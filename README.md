# BioNeuronCore — вычислительный движок нейронной сети

## Назначение

BioNeuronCore — движок для биологически-реалистичной симуляции нейронных сетей на C++17 с SYCL 2020 (Intel oneAPI DPC++). Вычисления выполняются на GPU (Intel, NVIDIA, AMD), с возможностью будущей трансляции на FPGA (Xilinx Vitis HLS). Код построен вокруг принципа **сегментированной модели нейрона**: каждый нейрон состоит из независимых электрических компартментов (сегментов), соединённых внутриклеточными связями.

**Формат файлов:** BION v12 (MAX_MODIFIERS=32, обратная совместимость с v3-v11). **Версия:** v0.20.0. **Тесты:** 156. **Модификаторов:** 198.

## Ключевые возможности

| Режим | Константа | Описание |
|-------|-----------|----------|
| **BIOLOGICAL** | `MODE_BIOLOGICAL` (0) | Все 198 типов модификаторов используют биологически-калиброванные модели (Hodgkin-Huxley, рецепторы нейромедиаторов, насосы, сигнальные каскады, Ca²⁺/K⁺/Cl⁻ гомеостаз, каналы ритмогенеза, генная экспрессия 46 генов, Cx36, TRP/ноцицепторы, транспортеры, AQP4). |
| **ARBITRARY** | `MODE_ARBITRARY` (1) | Пользователь может переопределить любой модификатор своей функцией. Пользовательские модификаторы (ID 0–127, весь диапазон плагинный) имеют приоритет над биологическими. |

### Бэкенды CPU/GPU

| Бэкенд | Сборка | Описание |
|--------|--------|----------|
| **CPU** | `libbiocore_gcc.a` (GCC) | Всегда доступен. Используется Studio по умолчанию. |
| **GPU** | `libbiocore_gpu_backend.so` (DPC++) | Загружается через dlopen. Требует Intel oneAPI runtime. Выбирается в тулбаре Studio. USM-указатели доступны с CPU. |

### Плагины модификаторов

Пользовательские модификаторы (ID 0–127) загружаются из `.so` файлов через `dlopen`. Каждый плагин экспортирует `biocore_plugin_init()` и `biocore_plugin_desc()` (JSON-дескриптор). API: `plugin_load()`, `plugin_load_directory()`, `register_user_modifier()`. Пример: `plugins/example_ca_plugin.cpp`.

### Хост-загрузчик (без SYCL)

`bion_loader_host.cpp` — загрузка/сохранение .bion в host-память (new[]/delete[]). Не требует Intel oneAPI. Используется в BioNeuronStudio для загрузки моделей.

### Архитектура: сегменты, нейроны, сеть

```
.bion файл → NetworkHeader → Neuron[] → Segment[] → IntraConnection[] → Synapse[]
```

**Сегмент (Segment)** — базовый электрический компартмент. Имеет:
- Геометрию: положение (x, y, z), длина, радиус → площадь мембраны → ёмкость
- Мембранный потенциал `V_m` (мВ)
- 7 внутриклеточных и 7 внеклеточных концентрации ионов (Na⁺, K⁺, Ca²⁺, Cl⁻, Mg²⁺, A⁻, H⁺)
- 15 типов нейромедиаторов во внеклеточной среде
- До 32 модификаторов (ионные каналы, рецепторы, насосы, миелин, сенсоры)
- Уровень ATP и температуру
- Транскрипционный сигнал `transcription_signal` (CREB-зависимая пластичность)
- Рабочий буфер тока `I_buffer` (обнуляется на каждом тике)

**Нейрон (Neuron)** — логическая группировка сегментов. Содержит:
- Диапазон сегментов `[segment_start, segment_start + segment_count)`
- Индекс сомы (`soma_index`)
- Порог спайка и тип

**Внутриклеточная связь (IntraConnection)** — резистивный мост между двумя сегментами:
- Осевой ток: `I = (V_a − V_b) / R_coupling`
- Сегменты накапливают до 16 входящих связей (быстрый доступ через `intra_connection_ids[]`)

**Синапс (Synapse)** — химическая/электрическая связь между нейронами:
- Пресинаптические ауторецепторы (до 8) — модулируют вероятность выброса
- Постсинаптические рецепторы (до 8) — создают ионные токи при связывании нейромедиатора
- Вероятностный выброс (xorshift32 RNG, seed = id ⊕ tick ⊕ V_m)
- Клиренс нейромедиатора из щели (экспоненциальный спад)
- Рефрактерный период
- Фасилитация и депрессия

## Симуляционный цикл (5 шагов на тик)

```
Шаг 1:   Токи модификаторов + обработка стимулов (I_clamp, ramp, ионные/лигандные инжекции) → I_buffer сегмента
Шаг 2:   Осевые токи (IntraConnection) → атомарное накопление в I_buffer
Шаг 2.5: Межсегментная диффузия (ионы, ATP, температура, транскрипция) по закону Фика
Шаг 3:   Синаптические токи (выброс → модуляция → пост-ответ → клиренс)
Шаг 4:   Обновление V_m = V_m + I_buffer / C_m × dt, сброс I_buffer, voltage clamp (перезапись V_m)
```

Каждый шаг синхронизирован (`q.wait()`), что гарантирует детерминированный порядок вычислений.

## Бинарный формат .bion

`.bion` — **единственный** конфигурационный файл сети. Содержит **все** данные: топологию, параметры сегментов, модификаторы (включая пре- и постсинаптические), режим симуляции. Никаких JSON/YAML/XML не требуется.

### Структура (v9)
```
[NetworkHeader]  84 байта — magic (0x42494F4E), version (9), mode, счётчики, num_nuclei, nucleus_version
[Neuron[]]       num_neurons × 24 байта
[Segment[]]      num_segments × 1692 байта
[IntraConnection[]] num_intra_connections × 16 байт
[Synapse[]]      num_synapses × 836 байт
[Nucleus[]]      num_nuclei × 412 байт — гены, белки, сигнальные кэши
```

### Свойства
- Все данные идут последовательно, без разрывов — возможна zero-copy десериализация
- Все структуры POD, `#pragma pack(1)` — FPGA-совместимость
- Только индексы в массивах, никаких указателей в файле
- Валидация при загрузке: magic, версия, границы индексов, лимиты модификаторов
- Поддержка save/reload (checkpoint) с идентичностью данных
- `build_id` и `timestamp` для отслеживания происхождения файла

## GPU-исполнение (SYCL)

- Все ядра компилируются через Intel DPC++/icpx с `-fsycl`
- Память: USM (`sycl::malloc_shared`) — единое адресное пространство host + device
- Switch-диспетчеризация вместо function pointers (несовместимы с SYCL device-кодом)
- Атомарные операции (`sycl::atomic_ref`) для потокобезопасного накопления токов
- Автоматический CPU-fallback при пользовательских переопределениях в ARBITRARY-режиме
- Поддержка GPU (Intel UHD/Iris/Arc, NVIDIA через native CUDA (nvcc)) и CPU

## FPGA-совместимость (проектная)

- Все структуры POD с `#pragma pack(1)` — фиксированные смещения
- Фиксированные массивы (нет динамического выделения в ядрах)
- Минимум ветвлений в вычислительном пути
- Потоковая читаемость .bion (фиксированные смещения = карта памяти)
- Код готов к синтезу в Xilinx Vitis HLS

## Ключевые биологические механизмы

- **Потенциал покоя** формируется балансом Na⁺/K⁺-каналов и Na⁺/K⁺-АТФазы
- **Потенциал действия** (спайк): деполяризация → активация Na⁺-каналов → инактивация → K⁺-реполяризация
- **Na⁺/K⁺-насос** противодействует ионному дрейфу, потребляя ATP; без него нейрон деполяризуется
- **Миелин** блокирует ионотропные токи на миелинизированных участках, оставляя активными перехваты Ранвье
- **Сальтаторная проводимость**: спайк перескакивает между перехватами Ранвье, ускоряя передачу
- **Вероятностный синаптический выброс**: модулируется пресинаптическими ауторецепторами, фасилитацией и депрессией
- **Клиренс нейромедиатора**: экспоненциальный спад концентрации в синаптической щели

## Биология синаптического контакта: active zone и PSD

В реальных синапсах ЦНС рецепторы и механизмы выброса нейромедиатора сконцентрированы не на всей поверхности нейрона, а в микроскопических специализированных зонах контакта. Использование полной площади цилиндрического сегмента (2πrl ≈ 300–3000 μm²) для расчёта синаптической проводимости биологически некорректно.

### Active zone (пресинапс, `pre_area`)

Активная зона — участок пресинаптической мембраны, где происходит стыковка и экзоцитоз синаптических везикул:

- **Размер в ЦНС:** ~0.05–0.2 μm² (один синапс). Крупные синапсы (calyx of Held, hippocampal mossy fiber boutons) могут достигать 1–2 μm² с множественными активными зонами.
- **Структура:** плотная решётка белков SNARE (syntaxin, SNAP-25, synaptobrevin), Ca²⁺-каналы (Cav2.1/Cav2.2), белки активной зоны (Bassoon, Piccolo, RIM, Munc13).
- **Функция:** определяет количество везикул готовых к немедленному выбросу (RRP — readily releasable pool, ~5–10 везикул на активную зону).
- **Ауторецепторы:** расположены перисинаптически (на расстоянии ~0.1–0.5 μm от активной зоны) — их плотность масштабируется на `pre_area`.

### PSD — постсинаптическое уплотнение (`post_area`)

PSD (postsynaptic density) — электронно-плотная структура на постсинаптической стороне:

- **Размер:** ~0.05–0.5 μm². Пропорционален размеру активной зоны (пре- и пост- стороны синапса согласованы по размеру через транс-синаптические сигналы).
- **Структура:** рецепторные кластеры (AMPA, NMDA, GABA-A), заякоренные скаффолд-белками (PSD-95, SAP97, Shank, Homer, GKAP), актиновый цитоскелет.
- **Функция:** проводимость синапса пропорциональна площади PSD × плотности рецепторов (~100–1000 рецепторов/μm²). Рецепторы распределены по PSD неравномерно: AMPA — по всей площади, NMDA — более центрально, mGluR — перисинаптически.

### Перисинаптическая организация

- **Перисинаптические рецепторы:** mGluR2/3, GABA-B, CB1 расположены на расстоянии ~0.1–1 μm от края PSD, вне прямого доступа к квантовому выбросу глутамата. Активируются при spillover (диффузия нейромедиатора за пределы щели).
- **Астроцитарная оболочка:** отростки астроцитов покрывают ~60–80% синаптического контакта, ограничивая spillover и экспрессируя транспортеры (EAAT1/2 для глутамата, GAT-1/3 для GABA).
- **Внесинаптические рецепторы:** до 30–50% рецепторов могут находиться вне синапса на поверхности сегмента. Они используют полную площадь сегмента (geometry fallback при `pre_area`/`post_area` = 0).

### Отражение в BioNeuronCore

- `Synapse::pre_area` и `Synapse::post_area` (значение по умолчанию 0.1 μm²) масштабируют проводимость рецепторов через `Modifier::state[7]` (scratchpad).
- `state[7]` выставляется перед каждым dispatch в `simulation_host.cpp`, `simulation.cpp`, и SYCL-ядрах.
- Если `pre_area`/`post_area` = 0 или не заданы, используется геометрическая площадь сегмента (обратная совместимость).
- Модификаторы-рецепторы (ионотропные и метаботропные) и пресинаптические модуляторы читают `state[7]` через `effective_area(m, s)`.
