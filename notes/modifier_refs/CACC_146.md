# CaCC / ANO2 (TMEM16B) — Ca²⁺-активируемый Cl⁻-канал

Тип: **MOD_CACC (146)**. Ca²⁺-активируемый Cl⁻-канал (аноctamin-2 / TMEM16B). GHK Cl⁻ (z=−1).

## Биология
- Экспрессия: реснички обонятельных нейронов (ORN), синаптические терминали фоторецепторов.
- Активируется внутриклеточным **Ca²⁺** (вход через CNG) и **напряжением** (сопряжённые).
- В ORN высокий [Cl⁻]ᵢ → Cl⁻-эффлюкс → **деполяризация** → усиливает ответ до ~80–90% (PNAS 2009, Li&Lin 2018).

## Как мы пришли к γ=2 пС (структурное обоснование)

**γ для TMEM16B в литературе НЕ сообщается.** Рассуждали от молекулярной структуры:

```
TMEM16B = димер (2 × 10 трансмембранных спиралей)
Пора = желоб/полость на ГРАНИЦЕ димера (scramblase-подобная), НЕ центральная пора
       ├─ ШИРОКАЯ            → ↑ γ (больше сечение)
       ├─ МЕЛКАЯ (короткий путь) → ↑ γ
       └─ СЛАБО селективная (нет плотного selectivity filter) → ↓↓ γ (нет компенсации
          дегидратации, высокие энергобарьеры) ← ДОМИНИРУЕТ
```

Слабая селективность + высокие барьеры → **маленькая γ (~1–8 пС)**.
Опора на гомолог: **TMEM16A** (ближайший структурный аналог с измерениями) γ ≈ **8 пС** (при высоком Ca²⁺, падает до суб-пС при низком).

→ **γ = 2 пС** (структурная оценка, НЕ чётко).

## Модель

```
ca_um    = intra_ions[ION_CA] × MM_TO_UM          // µM
m_inf    = Ca² / (Ca² + EC50²)                     // Hill n=2, EC50=4 µM
gate     += (m_inf − gate) · dt/τ                 // релаксация τ=2 мс
P_single = γ(2 пС) × GHK_GAMMA_PS_TO_P_CM_S       // γ→P (z=1)
I_Cl     = (P·density·CM_TO_M) × ghk_anion(V, cl_in, cl_out) × area × gate
intra[Cl] += I_Cl·dt/cpm                           // Cl⁻: += (анион)
return −I_Cl
```

V-зависимость НЕ моделируется отдельно (вторичная; клетка в гиперполяризованном диапазоне) — помечено «не чётко».

## Статус
✅ EC50=4 µM, Hill n=2, Cl⁻-селективность, роль — **твёрдо** (Cenedese 2011, PNAS 2009).
⚠️ γ=2 пС — **структурная оценка** (TMEM16B unitary в литературе не сообщается; гомолог TMEM16A ~8 пС).
⚠️ V-зависимость — не моделируется (вторичная).
