# IP3R (127) — IP3-рецептор (канал выброса Ca²⁺ из ЭПР)

**Тип:** MOD_IP3R (127). Категория Ca²⁺-гомеостаз (ЭПР).
**Роль:** IP3-управляемый канал выброса Ca²⁺ из ЭПР в цитозоль.
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **De Young & Keizer (1992)** — детальная 9-переменная кинетика IP3R.
- **Li & Rinzel (1994)** *J Theor Biol* 166:461 — HH-подобная редукция: m∞³·n∞³·h³.

## Модель (Li–Rinzel, динамическая инактивация)

```
J = v_rel · m∞³ · n∞³ · h³ · ([Ca]ER − [Ca])
m∞ = [IP3]/([IP3]+K_IP3),  K_IP3 = 0.13 µM
n∞ = [Ca]/([Ca]+K_act),    K_act = 0.2 µM
dh/dt = (h∞ − h)/τ_h,      h∞ = K_inh/(K_inh+[Ca]), K_inh = 1 µM, τ_h = 100 мс
```

**IP3 — локальный второй мессенджер** (state[]), честный каскад Gq→PLC→IP3:
```
dIP3/dt = k_PLC · mGluR(глутамат) − IP3/τ_IP3
mGluR = glu/(glu+EC50), EC50 = 10 µM
```

## Что исправлено (2026-08-19)

1. **Статическая bell-кривая** → полный Li–Rinzel (динамическая h).
2. **Суррогат `glutamate·0.1`** → честный каскад Gq→PLC→IP3 (IP3 в state[]).
3. **p_max магия** → v_rel = 5 с⁻¹ (чистый поток).
4. **charge_per_mole** → чистый поток (линейный градиент), масса сохраняется.
