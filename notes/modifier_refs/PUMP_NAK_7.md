# PUMP_NAK (7) — Na⁺/K⁺-АТФаза (Na/K-насос)

**Тип:** MOD_PUMP_NAK (7). Базовый модификатор — ионный гомеостаз.
**Роль:** активный транспорт 3 Na⁺ наружу : 2 K⁺ внутрь : 1 ATP. Электрогенный (нетто +1 заряд наружу, гиперполяризующий).
**Статус:** ✅ ДОСТОВЕРНО (цикл Поста–Альберса, 2026-08-19).

## Литература

- **Skou (1957)** *Biochim Biophys Acta* 23:394 — открытие (Нобель 1997).
- **Läuger (1991)** *Electrogenic Ion Pumps* — ATP-связывание k+ = 30·10⁶ M⁻¹s⁻¹, K_d = 3 µM.
- **Heyse, Wuddel, Apell & Stürmer (1994)** *J Gen Physiol* 104:197 — E1P→E2P = 22 s⁻¹ @20°C, Na-высвобождение ≥5000 s⁻¹.
- **Smith & Crampin (2004)** *Prog Biophys Mol Biol* 85:387 — термодинамический каркас цикла Поста–Альберса.
- **Gadsby / Rakowski / De Weer (1993)** — вольт-зависимость: кажущаяся валентность z_q ≈ 0.74–0.91.
- **Oka et al. (2010)** *J Theor Biol* 265:68 — K_Ko = 1.8 мМ, кардио-модель на базе Smith & Crampin.

## Модель: цикл Поста–Альберса (4-стадийный, steady-state)

```
E1·ATP ──a1──▶ E1P(Na₃) ──a2(V)──▶ E2P ──a3──▶ E2(K₂) ──a4──▶ E1·ATP
         ◀──────────        ◀────────          ◀──         ◀──
                (необратимы в физиол. диапазоне)    b2(V)
```

| Шаг | Переход | Константа | Значение |
|---|---|---|---|
| a1 | E1 → E1P (фосфорилирование) | k1·f_Na·f_ATP | 200 s⁻¹ |
| a2 | E1P → E2P (ЭЛЕКТРОГЕННЫЙ) | k2·exp(δ·z·F·V/RT) | 60 s⁻¹ @V=0 |
| b2 | E2P → E1P (обратный) | k2m·exp(−(1−δ)·z·F·V/RT) | 6 s⁻¹ @V=0 |
| a3 | E2P → E2 (дефосфорилирование) | k3·f_K | 200 s⁻¹ |
| a4 | E2 → E1 (высвобождение K⁺) | k4 | 60 s⁻¹ |

- f_Na = Na_i³/(Na_i³+K_Na³), K_Na = 10 мМ (Hill-3, три сайта).
- f_K  = K_o²/(K_o²+K_K²),  K_K = 1.5 мМ (Hill-2, два сайта).
- f_ATP = ATP_norm/(ATP_norm+0.1), ATP_norm = ATP_level/5 (Michaelis, K_m≈0.5 мМ).
- z = 0.8, δ = 0.5 (партиция заряда электрогенного шага).
- Внутренний v_max цикла ≈ 37.5 s⁻¹ (консервативно, Heyse 1994 Q10=2.7) — задаёт ФОРМУ v_norm.

## Одномолекулярная схема (2026-09-22)

Ток (единица — молекула): `I = N · k_cat · v_norm · e · Δz`, где
- `N = density · area` — число молекул насоса на сегменте (density — КЛЕТОЧНЫЙ параметр, молекул/µm²);
- `k_cat = 75 с⁻¹` — максимальный оборот (Peng/Hertz 2010: α2/α3 = 70–80 с⁻¹);
- `v_norm ∈ [0,1]` — нормированный оборот цикла (solution Кинга–Альтмана, форма);
- `e · Δz = +1.602e-19 Кл` — нетто заряд за цикл (электрогенный, наружу).

Убран суррогат `I_max = 5 µA/см²` (соответствовал 4163 молекул/µm² при k_cat=75 — выше литературы).

## Что исправлено (2026-08-19)

1. **Hill-произведение → цикл Поста–Альберса** — добавлена вольт-зависимость (ранее её не было),
   упорядоченное связывание + окклюзия, обратимость электрогенного шага.
2. **×1e3 на Na_i/K_o** (было `intra_ions[Na]·1e3 «M→mM»`) — УБРАН. Массив уже мМ ≡ моль/м³.
   Hill-факторы больше не насыщаются до 1.0 — насос реагирует на градиенты.
3. **Магический 1e-3** (NA_PUMP_PMOL_TO_NA) → честный `UA_PER_CM2_TO_NA = 1e-5` + `I_max = 5 µA/см²`.
4. **Магический 1e-7** (ATP) → `NA_K_PUMP_ATP_RATE_NA = 1e-5` (1 ATP/цикл, нормировка пула).
5. **ATP-фактор** — был `ATP_level` напрямую (0..5, мог быть >1 → усиление ×5). Теперь ATP_level/5 + Michaelis.
6. **Знак возврата** — был `+I` (положительный = деполяризующий по конвенции `V_m += I_buffer/C_m·dt`).
   Электрогенный +1 наружу → гиперполяризующий → теперь `-I`.
7. **Объём плагина** πr²L/20 → `segment_volume` (single-source), + `clamp_ions`.

## Тесты (test_pump_nak.cpp, 7 cases / 20 ассертов)
