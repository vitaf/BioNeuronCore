# Локализация и градиенты плотностей (общий механизм)

Модель проксимально-дистальных градиентов и диаметр-зависимости плотности каналов.
Механизм: `CompartmentBlueprint::ModEntry{type, density, gradient}` — `gradient` линейный множитель
`density(i)=density·(1+gradient·i/(N−1))`, i=0 проксимально → N−1 дистально. Плотность per-µm²,
итог = density(i) × area (area=2πrl — диаметр+длина сегмента).

## Кто участвует (распределение по дендриту)

| Группа | Модификаторы | Характер градиента |
|---|---|---|
| Na (Nav) | IONOTROPIC_NAK, NAP | AIS>сома>дендрит (AIS уже отдельно) |
| Kv | KvDR, Kv4.2(A), Kv7(M) | A-type↑дистально, M↓дистально |
| HCN | HCN1-4 | ↑дистально |
| Ca²⁺ | Cav1.3(L)↓, Cav3(T)~, Cav2.1(пресинапс) | L-проксимальнее, T-шире |
| K(Ca) | SK, BK | соматические |
| Na-утечка | NALCN | соматодендритный |
| Насосы/обменники | PMCA, NCX, KCC2, NAK | равномерно (gradient=0) |
| Рецепторы | AMPA/GABA/NMDA | постсинапс, равномерно по дендриту |

## Аксон (тоже градиенты)

| Канал | Градиент вдоль аксона |
|---|---|
| Na (IONOTROPIC_NAK) | AIS (макс) → спадает вдоль аксона (gradient<0); в миелине — узлы Ранвье |
| Kv (KvDR/Kv1.x) | вдоль аксона (реполяризация), может ↑ к терминали |
| Cav2.1 (P/Q) | → **пресинаптический терминал (бутон)**, не равномерно |
| K2P/NALCN | равномерно |

## Микродомены (не V_m-компартменты)

- **Бутон (пресинапс)** = микродомен `Synapse.bouton_Ca` — Cav2.1→Ca²⁺→синаптотагмин→выброс. НЕ отдельный V_m-сегмент (как в CPG).
- **Шипик (постсинапс)** = микродомен `post_area` + пост-Ca²⁺ — AMPA/NMDA локально, Ca²⁺ в шипиковой головке.
- Оба — локальные Ca²⁺-компартменты, а не полные электрические компартменты.

## Форма градиента (литература)

- **HCN в CA1**: сигмоидальная (нарастает ~7×, плато в stratum lacunosum-moleculare; Lörincz 2002, Magee 1998). Иммуно-золото в субикулуме ~55×.
- **HCN в коре L5**: экспоненциальная (Magee 1998).
- **Kv4.2 (A-type)**: ↑дистально (Hoffman 1997).
- Механизм: линейный профиль = первое приближение; экспоненциальный/сигмоидальный — калибровка этап 6.

## Значения градиентов (калибровка — этап 6)

Конкретные множители (gradient) per-канал per-тип-нейрона — из литературы:
HCN↑~7× (CA1), Kv4.2↑~4-5×, Cav1.3↓ (проксимальный). Насосы/обменники/рецепторы — gradient=0.

**Применено в neuron_library.h (2026-09-08):**
- **Cav1.3 (L-type)** → `gradient = -0.5` (проксимальный, ↓дистально) — исправлено с ошибочного `+0.5`.
- **HCN** → `gradient 6.0` (линейный), CA1 `6.6` (сигмоида), L5 `3.0` (экспонента) — ↑дистально.
- **Kv4.2 (A-type)** → `gradient 5.0` — ↑дистально.
- **Cav2.3 (R-type)** → `gradient 2.0` — дистальный дендрит.
- Исключения (без градиента, обоснованно): Kv4.2 на аксоне (реполяризация), Mitral HCN2 (Angelo 2011 — популяц. разнородность), Purkinje HCN1 (слабый Ih, равномерно).

## Правила (как делаем — согласовано 2026-09-02)

1. **Градиент — общий механизм** (`ModEntry.gradient`), применим к любому модификатору.
2. **Форма зависит от канала И типа нейрона** (не одна на всех): HCN сигмоида (CA1) / экспонента (L5), Kv4.2↑, Cav1.3↓, NaF/KDR равномерно.
3. **Механизм — линейный профиль** как первое приближение; сигмоида/экспонента — уточнение на этапе калибровки (6).
4. **Плотность per-µm²**, итог = density(i) × area (area = 2πrl: диаметр + длина сегмента). Диаметр/размер сегмента задаёт площадь → суммарное число каналов честно.
5. **Микродомены не V_m-компартменты**: бутон = `Synapse.bouton_Ca` (пресинапс), шипик = `post_area` + пост-Ca²⁺ (постсинапс).
6. **Дефолт gradient=0** (равномерно) для насосов/обменников/рецепторов и каналов без известного градиента.
7. **Корректировка**: уже сделанные нейроны — перепроверить честно по этим правилам; остальные — в рамках аудита каждого типа.
