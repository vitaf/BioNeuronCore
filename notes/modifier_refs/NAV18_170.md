# Nav1.8 (SCN10A) — TTX-R ноцицепторный Na⁺ (кандидат 170)

**Источник:** агент (WebSearch, 2026-09-03).

| Параметр | Значение |
|---|---|
| γ (пС) | **не определена экспериментально** (Channelpedia) — аналогия Nav 20 пС |
| Активация V½ / k | **−20 мВ** (натив. человек −10; мышь −45…−30) / 7–8 мВ |
| Инактивация V½ | **−25…−35 мВ** (натив. человек ≈ −35) |
| τ_акт | ~1–2 мс (медленная) |
| τ_инакт | ~5–13 мс (13.5 мс @ −20 мВ) |
| TTX | R (IC50 ~60 µM) |
| Особенность | медленная кинетика, несёт 80–90% входящего тока ПД в C-волокнах, работает при деполяр. где Nav1.7 инактивирован |

**PMID:** 8710901 (Akopian 1996), 10448219 (Akopian 1999), 11495938 (Renganathan 2001), 8632165 (Sangameswaran 1996).
