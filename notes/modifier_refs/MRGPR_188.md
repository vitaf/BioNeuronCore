# Mrgpr (Mas-related GPCR) — рецептор зуда/хемоноцицепции

**Тип:** метаботропный GPCR (НЕ ионный канал). Активирует TRPA1 через G-белок.

## Изоформы (грызун → человек)
| Изоформа | Лиганд | EC50 | G-белок | Каскад |
|---|---|---|---|---|
| MrgprA3 (мышь) | хлороквин (CQ) | ~28 µM | Gβγ | Gβγ→TRPA1 (PLC-незав., PIRT) |
| MrgprC11 (мышь) | BAM8-22 | 10–30 nM | Gαq/11 | PLCβ→IP₃/DAG→Ca²⁺→TRPA1 |
| MRGPRX1 (человек) | BAM8-22 / CQ | 14 nM / ~300 µM | Gαq/11 | PLCβ |

## Каскад (полный молекулярный)
```
лиганд → Mrgpr (GPCR) → Gαq/11 (или Gβγ)
  → Gαq: PLCβ → PIP₂ → IP₃ + DAG → IP₃R → Ca²⁺(ЭПР)
  → Gβγ: прямая активация TRPA1
  → Ca²⁺/Gβγ → TRPA1 → Na⁺/Ca²⁺ вход → деполяризация → ПД → зуд
```

## Нижестоящий канал
**TRPA1** (MOD_TRPA1=174, уже реализован). Активация TRPA1: AITC (электрофил, state[4]),
Ca²⁺ (анкириновые повторы), Gβγ. Десенситизация — Ca²⁺-зависимая.

## Ингибиция
- QWF — антагонист MrgprC11/MRGPRX2/MrgprA1/B2 (НЕ действует на MrgprA3/MRGPRX1).
- HC-030031 — антагонист TRPA1 (IC50 5.3–6.2 µM).

## Локализация
Непептидергические (IB4⁺) C-волокна DRG, периферические терминали эпидермиса, ~4–5% DRG («линия зуда»).

## Реализация (наша модель — GHK/ионы, No Surrogates)
- Mrgpr = метаботропный рецептор-модификатор (MOD_MRGPR), сигнальный (ток=0).
- Лиганд через `state[4]` (хлороквин/BAM8-22) — как AITC у TRPA1.
- Gαq-активация `state[0]` + десенситизация `state[1]` (GRK/β-аррестин), как `gq_signal`.
- Нижестоящий: Gαq→IP₃ (общий пул PLC_IP3_DAG)→IP₃R→Ca²⁺; Ca²⁺ активирует TRPA1.
- **Требует**: добавить Ca²⁺-зависимую активацию в TRPA1 (сейчас только Ca²⁺-десенситизация).
