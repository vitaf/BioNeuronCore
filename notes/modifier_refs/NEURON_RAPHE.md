# NEURON RAPHE — серотонинергические нейроны ядер шва (головастик, аналог DRN)

Справочник модификаторного состава. Тип: **нейромодуляторный** (5-HT, volume transmission).

## Биология
- **Тонический «clock-like» пейсмейкер** — спонтанная регулярная стрельба 0.6–1.2 Гц (до 6 Гц).
- Медленная регулярная пейсмейкерная активность обеспечивается координацией **11 ионных токов** (Tuckwell & Penington 2014, вычислительная модель DRN 5-HT).
- Высвобождает **5-HT** (серотонин) через volume transmission → 5-HT1A на cIN/dIN (Gi/o→GIRK), 5-HT2A на MN (Gq→↑Ca²⁺).
- **5-HT1A авторецептор** (соматодендритный): тормозит собственную стрельбу (отрицательная обратная связь) — механизм: ↑K⁺-проводимость (4-AP-чувствительный K⁺, НЕ SK/BK) + ↓Ca²⁺-ток (Penington 1990, Haj-Dahmane 1991).

## Модификаторный состав (ПОЛНЫЙ — литература Tuckwell & Penington 2014)
| Мод. | Белок/ток | Роль в пейсмейкере |
|---|---|---|
| IONOTROPIC_NAK (0) | fast Na⁺ (m³h) | фронт спайка |
| KV_DR (123) | delayed rectifier K⁺ (n⁴) | реполяризация |
| **KV42 (85)** | A-type K⁺ (I_A) | конкурирует с I_T в межспайковом интервале |
| **KV7_MCURRENT (112)** | M-type K⁺ (I_M) | медленный K⁺, модуляция частоты |
| **PIR_TTYPE_CALCIUM (96)** | T-type Ca²⁺ (Cav3.x, I_T) | низкопороговый Ca²⁺-вход, конкурирует с I_A |
| **CAV13 (1)** | L-type Ca²⁺ (Cav1.3, I_L) | высокопороговый Ca²⁺-вход |
| (N-type Ca²⁺) | Cav2.2 | высокопороговый Ca²⁺ — **изоформа #8 (не реализована)** |
| SK_CHANNEL (103) | SK (KCa2.x) | долгая AHP |
| **BK_CHANNEL (104)** | BK (KCa1.1) | быстрая реполяризация |
| **HCN (I_H)** | HCN2/3 (130/131) | деполяризующий «sag», облегчает спонтанную активность |
| K2P_LEAK (107) | leak | покой |
| PUMP_NAK (7) | Na/K-АТФаза | гомеостаз |

> **5-HT1A авторецептор** — Gi/o-метаботропный (Gi/o → GIRK K⁺-проводимость). Должен быть добавлен как рецептор на соме (не отдельный канал).

## Литературные плотности (Tuckwell & Penington 2014, извлечено из arXiv 1212.1096)

**Модель rat DRN 5-HT нейрона (однокомпартментная, 11 токов).** Опорные значения (Set 1: C=40 пФ, A=4000 µm²; Set 2: C=88.61 пФ, A=8861 µm²):

| Проводимость | Set 1 (µS) | Set 2 (µS) | Плотность (мС/см², Set 1) |
|---|---|---|---|
| gNa (INa) | 2.00 | 1.5 | **50** |
| gKDR (IKDR) | 0.5 | 0.5 | **12.5** |
| gA (I_A) | 0.479 | — | **12** (12000 µS/см²) |
| gN (N-type Ca) | 0.1 | — | 2.5 |
| gSK | 0.003 | 0.015 | 0.075 |
| gT / gL / gBK / gH | — | — | выписать из секций 4–6, 9 |

**Одноканальные проводимости:**
- L-type Ca (Cav1.x): **γ = 23 пС** (Penington et al. 1991).
- I_A: g = 20.5 нС whole-cell, V_a=−52.5 мВ, k_a=16.5 мВ, m⁴, V_rev=−105 мВ (Penington & Tuckwell 2012, arXiv 1107.3450).

**Покой:** V_R = −60 мВ (Set 1) / −67.8 мВ (Set 2). τ_membrane = 7.4–53.5 мС (среднее 32.5).

**Перевод:** g(мС/см²) = g(µS) × 25 (для Set 1, A=4000 µm² = 4e-5 см²). 1 нС/пФ ≡ 1 мС/см² (при Cm=1 µФ/см²).

> ⚠️ Это **rat/mouse (млекопитающие)** значения — эталон для головастикового RAPHE (модельной абстракции). Точная головастиковая калибровка — этап 6, но плотности теперь с источником.

- 5-HT1A: Gi/o → GIRK (тип MOD_GIRK или эквивалент Gi/o-каскада).
