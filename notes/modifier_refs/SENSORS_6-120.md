# Сенсорные модификаторы (физические трансдьюсеры) — типы 6, 94, 95, 108, 115-120

Аудит #13. Дата: 2026-08-21. Метод: [[modifier-audit-method]].

## Природа категории

Физические трансдьюсеры: превращают стимул (температура/механо/pH, свет, вибрация,
гравитация, угловое ускорение, E-поле, B-поле, ATP) в сенсорный ток (деполяризация).
Вход — из `state[1]` (внешний parametric input, выставляется средой). density × area —
калибровка амплитуды (число трансдьюсеров). Каждый имеет молекулярную основу.

## Диагноз нечестности

1. **Hunger (94): `atp_norm = ATP_level * 1000`** — баг масштаба. ATP_level в мМ (0..5);
   нормировка должна быть `/5.0f` (как в mTORC1), а не `×1000`. Сейчас hunger всегда ≈0.
2. **Physical (6): pH-сенсор читает `extra_ions[0]` = Na⁺** вместо H⁺ (суррогат; H⁺ нет
   в модели). Убрать pH-компонент, оставить температуру (TRPV1/TRPM8) + механо (Piezo).
3. **Light (95): `(void)gain`** — gain вычислен, но не используется (мёртвый код).
4. **PIR (93): Ом-модель композита HCN+T-Ca** (g_h=0.01, g_CaT=0.005, реверсы V+20/V−120).
   Дубликат: cpg_config уже экспрессирует честные HCN1/HCN2 + T-Ca. **УДАЛИТЬ мёртвый код,
   ID 93 зарезервировать (deprecated)** — как PIR_HCN (97).
5. **Scaling (0.015–0.02)** в return сенсоров — калибровка gain (амплитуда сенсорного тока
   на единицу P_open), не литературная константа. Задокументировать; density × area уже
   масштабирует ток.

## Решения (согласовано 2026-08-21)

1. **Hunger**: `/5.0f`. 2. **Physical**: убрать pH-суррогат. 3. **Light**: убрать void-gain.
4. **PIR (93)**: удалить код, ID зарезервировать. 5. **Scaling** — задокументировать.
6. **density** — уже в return (не менять).

## Границы

Меняется ТОЛЬКО тело функции + плагины + тесты. `Segment/Modifier`, `state[]`, `#pragma pack`,
BION, диспетчеры — НЕ трогаются. ID сенсоров сохраняются (кроме PIR 93 → reserved).
