# NEURON SER — орексиновый поисковый интернейрон (головастик, аналог orexin/hypocretin нейрона)

Справочник модификаторного состава. Тип: **нейромодуляторный/поисковый** (орексин/гипокретин, глутамат ко-выброс).

## Биология
- **Интринсивный пейсмейкер** (Eggermann 2003) — активность преимущественно в бодрствовании, важна для цикла сон-бодрствование.
- Интегрирует голод (HYPO→AMPA) и обоняние (ORN→GLY), драйвит dIN — исследовательское поведение.
- Орексиновые нейроны — **глутаматергические** (ко-выброс глутамата + орексин).
- **Пейсмейкерные токи** (Hodgkin-Huxley модель орексинового нейрона):
  - fast Na⁺, fast-inactivating K⁺ (iK), slowly-inactivating K⁺ (iK2), **HCN (ih)**, **T-type Ca²⁺ (iT)**, **Ca²⁺-зависимый неселективный катионный ток (iCAN)**, Ca-leak (iCal), leak.
- **HCN** даёт деполяризующий «sag»; **T-type Ca** + **iCAN** — Ca²⁺-зависимая деполяризация.

## Модификаторный состав (ПОЛНЫЙ — литература)
| Мод. | Белок/ток | Роль |
|---|---|---|
| IONOTROPIC_NAK (0) | fast Na⁺ | фронт спайка |
| KV_DR (123) | fast-inactivating K⁺ (iK) | реполяризация |
| **KV42 (85)** | slowly-inactivating K⁺ (iK2) | форма спайка, частота |
| **HCN2 (130)** | HCN (ih) | деполяризующий «sag» |
| **PIR_TTYPE_CALCIUM (96)** | T-type Ca²⁺ (iT) | низкопороговый Ca²⁺-вход |
| K2P_LEAK (107) | leak (il) | покой |
| PUMP_NAK (7) | Na/K-АТФаза | гомеостаз |
| + Ca²⁺-гомеостаз | PMCA/NCX/KCC2/CA_LEAK/CA_BUFFER | Ca²⁺-клиренс |

> **iCAN** (Ca²⁺-зависимый неселективный катионный ток, TRPM4/5) — **изоформа #8, НЕ реализована**. Пока компенсируется Ca-leak + HCN + T-type.

## Литература
- **Eggermann E, Bayer L, Serafin M, et al. (2003)** — интринсивный пейсмейкер орексиновых нейронов.
- **Williams KE (REU)** — «Model of an Orexin Neuron» (Hodgkin-Huxley): iNa, iK, iK2, ih, iT, iCAN, iCal, il.
- **The neuropeptides orexin-A/orexin-B (hypocretin-1/-2)** — Physiol Rev 2024 (обзор).

## Литературные плотности (Williams REU-модель орексинового нейрона, Table 1)

Абстрактная модель (c=1, нормализованная ёмкость). Пропорции проводимостей корректны, абсолютные G — пересчитать на этапе 6:

| Ток | g (µS) | V_rev (мВ) |
|---|---|---|
| iNa | **290** | +50 |
| iK | **20** | −77 |
| iK2 | gmaxk2a=16, gmaxk2b=10 | −77 |
| ih | **0.037** | −10 |
| il | **0.3** | −54.4 |
| iCAN | **3** | (V_can) |
| iT | p_ca (permeability, не g) | — |

Покой −57 мВ, спонтанная стрельба 3–4 Гц, спайк ~80 мВ. γ: HCN ≈ 1 пС, T-type (Cav3.x) ≈ 8 пС.

> Пропорция: gNa ≫ gK > gK2 > gCAN > gl > gh. iCAN (TRPM4/5) — изоформа #8, пока компенсируется Ca-leak + HCN + T-type.

## Статус
❌ **НЕПОЛНЫЙ** — отсутствуют HCN, T-type Ca, KV42 (iK2). Ca²⁺-гомеостаз полный. iCAN — изоформа #8. Модификаторы MOD_HCN2, MOD_PIR_TTYPE_CALCIUM, MOD_KV42 реализованы — добавить в состав.
