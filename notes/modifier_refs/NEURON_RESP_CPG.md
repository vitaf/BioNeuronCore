# NEURON_RESP_CPG — pre-Bötzinger дыхательный пейсмейкер (головастик)

**Файл кода:** `neuron_library.h` (RESP_CPG, ~936)
**Статус:** справочник для согласования (аудит #9) — обновлён 2026-09-02 (Krey 2010 / Revill 2021)

## Литературный прототип: pre-Bötzinger inspiratory pacemaker
Dbx1⁺ глутаматергические нейроны вентролатеральной медуллы — ядро генератора вдоха.

**⚠️ Амфибийный аналог:** у Xenopus есть «lung oscillator» (фиктивная лёгочная вентиляция) —
Kimura 2010; Vasilakos & Wilson 2005. Гомология НЕ 1:1 (буллфрог r5→лёгочные, r7→жаберные)
⇒ RESP_CPG = **экстраполяция млекопитающего pre-BötC** (маркер честности).

- **Нейротрансмиттер:** глутамат (VGLUT2+, Dbx1+). `nt_released=NT_GLUTAMATE` ✅.
- **Морфология (Hayes 2017, Sci Data):** сома ~319 мкм² (оси ~26×16 мкм); дендриты 4.2 (3–8),
  диаметр 0.76–1.6 мкм, длина 1427–2055 мкм. **Коррекция: Dbx1⁺ нейроны БЕЗ шипиков**
  (шипики у не-Dbx1⁺). Площади: сома ~319 мкм²; дендрит r≈0.4–0.8 мкм, l≈1.4–2.1 мм → area=2πrl.
- **Каналы (КЛЮЧЕВЫЕ):**
  - **NaP (persistent Na)** — критичен, активация ~−60 мВ, V½≈−40. gNaP 92.6±33 пСм/пФ (bursters)
    vs 42.1 (Del Negro 2002, PMID 12424313); I_peak −50…−200 пА.
  - **CAN (I_CAN)** = **TRPM4/TRPM5** (Ca²⁺-активируемый неселективный) — до 96% нейронов,
    инспираторный драйв-потенциал (Pace 2007; Crowder 2007). Плотность НЕ опубликована.
  - **KNa/Slack (KCNT1/2)** — **терминация вдоха** (Krey 2010, PMID 21151816; Revill 2021).
    Вместе с Na/K-насосом + KCNQ + KDR.
  - **TASK (K2P)** — базовая K⁺-утечка / возбудимость (Koizumi 2008/2010), НЕ терминация.
  - SK (sigh-вспышки), HCN (Ih — взаимоисключается с IA), Kv/KDR, Na.
- **Электрофизиология:** RMP −46±1 мВ; R_in 340±34 МΩ; C_m 69 пФ; bursting (10–30 мВ драйв).
- **Локализация:** NaP диффузно; Ih/IA соматодендритные (взаимоисключающие); CAN через Ca²⁺.
- **Миелин:** нет.

## Ключевая находка (ИСПРАВЛЕНО 2026-09-02)
`MOD_KNA_CHANNEL 0.2` (Slack) — **ОБОСНОВАН** литературой: терминация вдоха =
KNa/Slack (KCNT1/2) + Na/K-насос + KCNQ + KDR (Krey 2010; Revill 2021). Пометка
«не подтверждён» — **устарела**. TASK — отдельная утечка (не замена KNa).

## План правки (после согласования)
- KNa/Slack — ОСТАВИТЬ (обоснован терминацией), маркер источника.
- Добавить TASK (K2P-утечка) — базовая возбудимость.
- NaP — уточнить плотность (gNaP 92.6 пСм/пФ bursters).
- RMP −60 → −46 (pre-BötC).
- CAN (TRPM4/5) — нет в палитре (пометить как будущую изоформу).
- γ/Po/G для CAN/TASK/KNa/KCNQ/KDR — «нужна литература».

## Дополнение (агент 2026-09-02) — γ/Po CAN/TASK/KCNQ/KDR (закрыт пробел)

|---|---|---|---|

| **TASK-1 (K2P3.1)** | **~14** (14.2±0.4 @−60 мВ) | фоновый | COS-7 / carotid body |
| **TASK-3 (K2P9.1)** | **32–38** (37.8±0.7 @−60) | фоновый | COS-7 / DRG |
| **KCNQ2/3 (M-current)** | **7–9** (9.0±0.3 гетеромер) | ~0.30 @0 мВ | Selyanko 2001 (J Physiol 534:15) |
| **KDR** | Kv2.1 **~10**; Kv3.1/3.2 — γ отдельно не найден (~27 пС нужен первичн. источник) | voltage-dep. | Kv2.1 Physoc; Kv3 активация >−10 мВ (Rudy & McBain) |

- KCNQ2 гомомер 5.8±0.3 пС, KCNQ3 гомомер 9.0±1.1 пС (Selyanko 2001). Po(0 мВ): KCNQ2/3 0.30, KCNQ2 0.15, KCNQ3 0.59.
- KDR в pre-BötC = Kv2.1 + Kv3.1/3.2 (fast-spiking delayed rectifier, активация >−10 мВ, быстрая деактивация).
- Плотности: density = G·10/(γ·Po). CAN Po — Ca²⁺-зависимый (не фикс.), G CAN плотность в литературе не публикована.
