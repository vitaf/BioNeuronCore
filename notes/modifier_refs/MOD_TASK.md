# MOD_TASK — TASK (K2P TASK-1/3) фоновая K⁺-утечка

**Тип:** MOD_TASK (151) — новая изоформа (задача 8).

## Литература
- **TASK-1 (K2P3.1/KCNK3): γ ≈ 14 пС** (14.2±0.4 @−60 мВ, COS-7/carotid body).
- **TASK-3 (K2P9.1/KCNK9): γ ≈ 32–38 пС** (37.8±0.7 @−60 мВ).
- **Фоновый (voltage-independent)** — открыт при всех V_m, K⁺-селективная утечка. Чувствителен к pH/O₂ (TASK-1 в carotid body).
- Po фоновый ≈ 0.2–0.4 (leak-канал).
- Локализация: диффузно (сома), задаёт R_in/базовую возбудимость. Отличается от TREK-1 (K2P_LEAK, γ=100 пС, механо/термо-чувствительный).

## Молекулярные константы (для модификатора)
- γ ≈ 30 пС (среднее TASK-1/3); Po ≈ 0.3 (фоновый); без гейтинга (voltage-independent).
- **pH-ингибиция**: IC50 pH 6.7 (Talley 2000, Duprat 1997) — кислый pH закрывает; pH через state[4] (по умолчанию 7.4).
- GHK-поток K⁺ (z=1), open_prob = Po/(1+10^(6.7−pH)).
- **O₂/гипоксия (#31, реализовано 2026-09-03):** TASK **НЕ интринсивно O₂-чувствителен** — чувствительность даёт митохондриальный/метаболический сигналинг (цианид/FCCP дают тот же эффект, что гипоксия). Прямого PO₂ IC50/Hill НЕ существует.
  - Модель: state[5]=PO₂ (мм рт.ст.) → метаболич. сигнал state[6] (K=40 мм рт.ст., τ=1 с) → `Po *= (1 − 0.5·m_hyp)`.
  - Buckler 2000: PO₂ 150→40 → ток падает ~20% (экстраполяция до ~50% при полной гипоксии).
  - ⚠️ Это метаболический каскад-прокси (митохондрии), НЕ прямой PO₂-гейт — полный каскад (ATP/AMPK) — отдельная задача.

## НЕ нужны для модификатора (клеточный уровень, этап 6)
- G (мС/см²) — density = G·10/(γ·Po).
- Применение: RESP_CPG (терминация/базовая возбудимость), VLPO, гранулярные клетки мозжечка, carotid body.
