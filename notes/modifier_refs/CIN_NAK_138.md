## ⚠ ОТКЛОНЕНИЕ ОТ Table 3 (прозрачно, решение от 2026-08-25)

**В статье напечатано `C = 0.1` у α m_Na. Мы используем `C = 1.0`.**

**Почему (перекрёстная верификация):**
1. **Физическая нереальность.** `C=0.1` даёт α_m_max = 13.26/0.1 = 132/мс → τ_m_min = **7.5 мкс** —
   ниже предела конформации белкового ионного гейта (~20 мкс). Такой кинетики не существует.
2. **Выброс среди типов.** C у остальных 6 типов: aIN 0.5, MN 1, dIN 4, RB 1, dlc 3, dla 1.2.
   cIN C=0.1 — аномалия на порядок.
3. **Оригинал Dale (1995) — C = 1** (значения в скобках Table 3). Sautois унаследовал C≥0.5 везде,
   кроме cIN.
4. **Внутреннее противоречие статьи.** C=0.1 даёт rise ~1000 мВ/мс — статья заявляет, что модель
   «подогнана под Table 1» (rise 124 мВ/мс). Table 3 (C=0.1) не воспроизводит Table 1. → опечатка.

**Измеренная Na-активация Xenopus (Dale 1995): τ = 0.1–0.25 мс.** При C=1.0 наш τ_m на пороге =
0.163 мс — **совпадает**; при C=0.1 τ_m_min = 7.5 мкс — на 1–2 порядка быстрее.

**Вердикт:** `C=0.1` — транскрипционная ошибка (не отдельная изоформа). Исправлено на `C=1.0`
(= Dale/MN). Это исправление единственной молекулы, а не создание новой изоформы.

**Эффект исправления (dt=0.01, чистый cIN):**
| | C=0.1 (как в статье) | C=1.0 (исправлено) | Sautois Table 1 |
|---|---|---|---|
| rise rate | 1062 мВ/мс | 514 мВ/мс | 124 мВ/мс |
| peak | +50 мВ | +43 мВ | +32 мВ |

Остаточное превышение (~2× относительно dIN, у которого rise 166 vs 85) — следствие gNa cIN=500
против dIN=210 нС (реальная биология, Table 2) + Max-Biology распаковка E_Na через Нернст (+59.5
против фикс. VNa=+50). Систематический ~2× фактор общий с dIN (зааудитено ранее, принято).
