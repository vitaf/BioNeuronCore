# NMDA (9) — ионотропный глутаматный рецептор

**Тип:** MOD_NT_RECEPTOR_NMDA (9).
**Роль:** медленный возбуждающий ток, Ca²⁺-вход, Mg²⁺-блок (коинциденция-детектор).
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **Mayer & Westbrook (1987)** *J Physiol* 394:501 — P_Ca/P_Na = 10.6, P_K/P_Na ≈ 1, Mg²⁺-блок.
- **Jahr & Stevens (1990)** / **Ascher & Nowak** — Mg²⁺-блок (Woodhull, δ≈0.8-1.0).

## Модель (GHK + Mg²⁺-блок)

```
I = P_max · density · r · GHK(P_Na:P_K:P_Ca) · mg_block
r: tau_rise=5 мс, tau_decay=50 мс
P_Na:P_K:P_Ca = 0.08:0.08:0.84   (P_Ca/P_Na=10.6, P_K/P_Na=1)
mg_block = 1/(1 + ([Mg]/K_0)·exp(−δ·z·F·V/RT)), K_0=3.57 мМ, δ≈0.83
```

E_rev ≈ +10 мВ (Ca²⁺-проницаемость тянет в плюс).

## Что исправлено (2026-08-19)

1. **P_Na:P_K:P_Ca 0.6:0.2:0.2 → 0.08:0.08:0.84** (P_Ca был занижен ~30×, P_K ~3×).
2. **Parity-баг:** плагин (EC50=0.005, tau_rise=2.0) ≠ fallback (EC50=1.0, tau_rise=5.0) → плагин приведён к fallback.
3. **Single-source:** параметры в units.h (NMDA_*), Mg²⁺-блок именованными константами.

## Тесты (test_nmda.cpp, 3 cases / 4 ассертов)

Mg²⁺-блок снимается при деполяризации, E_rev > 0 (Ca-проницаемость), без глутамата ток ≈ 0.
