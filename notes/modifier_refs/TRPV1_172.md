# TRPV1 — тепло/капсаицин канал (кандидат 172)

**Источник:** агент (WebSearch, 2026-09-03).

| Параметр | Значение |
|---|---|
| γ (пС) | **50–100** (~90 @ +60 мВ, наружу-выпрямляющий) |
| Селективность | P_Ca/P_Na ≈ **10** (катион-неселективный, Ca-предпочтительный) |
| Активация | капсаицин + тепло >43 °C; pH<6 (порог ↓ до ~30 °C) |
| V½ | ~+150 мВ (комн. темп.); тепло/капсаицин/протоны сдвигают влево |
| EC50 капсаицин | ~0.5–1 µM |

**PMID:** 9349813 (Caterina 1997), PMC2714404, PMC4764576, Bevan 2014.

⚠️ Отличие от существующего MOD_NT_RECEPTOR_TRPV1 (16, ионотропный лиганд-гейт): здесь — тепло-гейт + капсаицин, неселективный катионный канал с P_Ca/P_Na≈10.
