# GAT3 (SLC6A11) — глиальный транспортер GABA

Тип: **MOD_GAT3 (149)**. Na⁺/Cl⁻-сопряжённый транспортер (SLC6). Заменяет tau_clearance для GABA.

## Биология
- Глиальный транспортер GABA (астроциты) — клиренс GABAергических синапсов.
- Семейство **SLC6** (Na⁺/Cl⁻-зависимые), тот же фолд что GlyT1/GAT1.

## Стехиометрия и кинетика (литература)
| Параметр | Значение | Источник |
|---|---|---|
| Стехиометрия | **1 GABA : 2 Na⁺ : 1 Cl⁻** (внутрь), net +1 | (общепринятая; альтернатива 3 Na⁺ — сомнительна) |
| GABA K_m | **≈ 0.8 µM** (высокое сродство) | SLC6A11 |
| Локализация | астроциты (GAT1 — нейрональный) | |

## Модель (shared-хелпер)
```
захват = I_max·density·area·(GABA/(GABA+K_m))   // Michaelis-Menten
за цикл: 2 Na⁺ внутрь + 1 Cl⁻ внутрь + 1 GABA внутрь (net +1)
I = +1 заряд/цикл (деполяризующий)
```

## Отличие от GLAST (SLC1)
- GLAST = SLC1: 3 Na⁺ + H⁺ + Glu / **1 K⁺ наружу**.
- GAT3 = SLC6: 2 Na⁺ + **1 Cl⁻ внутрь** (Cl⁻-котранспорт, без K⁺).

## Статус
✅ Стехиометрия 1 GABA/2 Na⁺/1 Cl⁻, K_m≈0.8 µM — твёрдо. ⚠️ K_m в отн.ед. (GAT3_K_M_REL=0.5) — калибровка. Нейрональный GAT1 (SLC6A1) — не смоделирован.
