# MOD_KV34 — Kv3.4 (KCNC4) A-type fast-inactivating K⁺-канал

**Тип:** MOD_KV34 — новая изоформа (fast-spiking, A-type высокопороговый).

## Литература
- **Активация V½ ≈ +19.1 мВ** (slope 11.3 мВ); **инактивация V½ ≈ −15 мВ** (slope −7.4) — Rudy et al. (цит. по модели).
- **A-type быстро инактивирующий** — N-терминальный «ball» домен окклюдирует пору; фосфорилирование серинов ворот инактивации ↓/убирает быструю инактивацию.
- Высокопороговый: активация ~−10 мВ, быстрый подъём, быстрая инактивация.
- Экспрессия: ЦНС + быстрые скелетные мышечные волокна.

## Молекулярные константы
- V½_акт ≈ +19 мВ (k=11.3); V½_инакт ≈ −15 мВ (k=−7.4); τ_инакт быстрая (N-ball).
- m·h (быстрая N-инактивация); GHK K⁺ (z=1). γ — нужна лит-ра.

## V-зависимая кинетика (исправлено 2026-09-22, Фаза 0 аудит динамики)
Было: τ_m=2 мс, τ_h=10 мс — фиксированные подгоны. Стало: V-зависимые τ(V) по Rudy et al.
(EMBO Mol Med 2014, suppl. Table D5):
- **τ_m(V) = 40 − 37.7/(1+exp(−V/28))** мс — активация (40 мс при гиперполяр. → 2.3 мс при сильной деполяр.).
- **τ_h(V) = 12 + 165.6·exp(−V/11.2)** мс — N-ball инактивация (~13.9 мс @ +50 мВ, WT 9.4 мс).
  Расходится при глубокой гиперполяр. (recovery) → cap 2000 мс (числ. стабильность; точная recovery τ — нужна лит-ра).
Хелперы `kv34_m_tau`/`kv34_h_tau` в modifier_helpers.h (single-source: fallback + плагин mod_159).

## Применение
Fast-spiking интернейроны (часть), параллельно Kv3.1.
