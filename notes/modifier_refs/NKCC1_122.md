# NKCC1 (122) — Na⁺-K⁺-2Cl⁻ котранспортёр

**Тип:** MOD_NKCC1 (122). Категория Ca²⁺/K⁺/Cl⁻ гомеостаз.
**Роль:** электронейтральный 1 Na⁺ : 1 K⁺ : 2 Cl⁻ внутрь, Cl⁻-ЗАГРУЗЧИК (антагонист KCC2).
Ключевой в онтогенетическом Cl⁻-переключателе (ранний: NKCC1↑ → GABA деполяризующее).
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **Delpire & Gagnon (2011)** *Am J Physiol Cell Physiol* 301:C1074 — кинетика, 1:1:2,
  упорядоченное связывание (Cl⁻ первый → Na⁺ → второй Cl⁻ → K⁺).
- **Gamba (2004)** *Physiol Rev* — CCC-котранспортёры, K_m(Cl⁻_i)≈50 мМ (ниже сродство чем KCC2 ~7мМ).

## Модель (электронейтральный поток)

```
J [моль/с] = V_max · density · area · f_Na · f_K · f_Cl · trans_stim · trans_inhib
f_X = X_i/(X_i+K_m),  K_m(Na⁺_i)=10, K_m(K⁺_i)=15, K_m(Cl⁻_i)=50 мМ
trans_stim = Na_o/(Na_o+0.5мМ),  trans_inhib = 1/(1+K_o/0.2мМ)
Δ[Na]i = Δ[K]i = Δ[Cl]i/2 = +J·dt/(NA·vol)   // чистый поток, 1:1:2 внутрь
return 0.0  // электронейтральный
```

- V_max = 7 нмоль/(см²·с) (высокоёмкостный, чуть быстрее KCC2 5).

## Что исправлено (2026-08-19)

1. **Магический v_max=0.001** («mol/s/m²») → **V_max=7 нмоль/см²/с**.
2. **Транспорт через charge_per_mole (фальшивый ток)** → **чистый поток** Δc=J/vol.

## Одномолекулярный перевод (отложен, 2026-09-22)

Точного k_cat для NKCC1 нет (есть rate constants forward 1002 с⁻¹, backward 2255 с⁻¹;
плотность ~6000/µm² — модельная оценка). **Вариант A (выбран):** оставлен эмпирический V_max.

**Вариант B (запасной, при проблемах в нейронах):** `flux = N·k_cat·f_Na·f_K·f_Cl·trans·dt/N_A`,

→ V_max ≈ 0.66 нмоль/см²/с (~10× ниже текущего 7).
