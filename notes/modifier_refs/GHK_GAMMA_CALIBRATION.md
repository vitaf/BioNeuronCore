# Калибровка переводной константы γ→P (GHK_GAMMA_PS_TO_P_CM_S)

Дата: 2026-08-21. Этап 6 (интеграция). Исправление ошибки этапа 2 SI-рефакторинга.

## Проблема

Константа `GHK_GAMMA_PS_TO_P_CM_S = 2.77e-17` (введена на этапе 2) занижала
проницаемость всех 49 GHK-каналов в ~6.7e9 раз → каналы давали ничтожный ток
при density~1 → CPG не генерировал ритм (0 switches).

## Формула γ→P (литература)

Одноканальная проводимость γ и проницаемость P связаны через линеаризованный GHK:

**γ = (z²F²/RT) · P · c**  ⟺  **P = γ · RT / (z²F² · c)**

Источники:
- NEURON `ghk.inc` (ModelDB 74298): `g = ρ z² c₀ F²/RT`.
- Hille, *Ionic Channels of Excitable Membranes*: `g = (z²F²/RT)·P·c`.
- NeuroML2 GHK/Nernst (opensourcebrain.org/projects/ghk-nernst).

Размерность: P — объёмная проницаемость [см³/с] (для одиночного канала),
γ [С], c [моль/см³].

## Численная проверка (литература)

BK-канал (γ=22 пС, c=100 мМ): `P = 22e-12 · 2578 / (96485² · 1e-4) = 6.1e-14 см³/с`
— совпадает с Grygorczyk, Schwarz & Passow (Biophys. J. 45:693, 1984). ✓

## Вывод константы в нашей схеме

`ghk_current_nA(P_cm_s, z, V, c_in, c_out, area_um2, open)`:
```
I[нА] = P_cm_s[см/с] · flux[Кл/м³] · area[µm²] · 1e-5 · open
flux = ghk_monovalent(V, c_in, c_out) = F²·V·0.001/(RT) · GHK_член
```

`P_cm_s = γ[пС] · GHK_GAMMA_PS_TO_P_CM_S · density` (density = каналов/µm²).

Требование: в пределе V→0 при симметричной концентрации ток должен совпадать с
омическим `I = N·γ·V` (N = density·area). Отсюда:

**GHK_GAMMA_PS_TO_P_CM_S = RT · 1e2 / (F² · c_ref)**

Численно (T=310.15 K, c_ref=150 моль/м³):
`GHK_GAMMA = 2578 · 100 / (9.309e9 · 150) = 1.847e-7` — подтверждено численно
(одинаково для K⁺ γ=100 пС и Na⁺ γ=27 пС).

**Divalent (z=2, Ca²⁺, c_ref=2 моль/м³):**
`GHK_GAMMA_PS_TO_P_CM_S_DIV = 3.462e-6` (подтверждено численно).
