# KV_DR (123) — Delayed rectifier K⁺ канал (Kv1.1, KCNA1)

**Тип:** MOD_KV_DELAYED_RECTIFIER (123). Категория #5 — ионные каналы Na/K/Ca/Cl.
**Роль:** быстрая реполяризация спайка, без быстрой инактивации.
**Использование:** только в библиотеке (`biological_library[123]`); НЕ в CPG-ядре
(dIN/cIN/aIN/MN используют Kv4.2 A-type mod_85, а не KV_DR).

## Литература

- **Stühmer W. et al. 1989**, *EMBO J* 8:3235 — молекулярная основа Kv1.x.
- **Gutman GA et al. 2005**, *Pharmacol Rev* 57:473 — номенклатура Kv (IUPHAR).
- Таблица PMC2838721 Table 1 — Kv1.1 (KCNA1) параметры.

## Характеристики Kv1.1 (KCNA1) — низкопороговый KDR

| Параметр | Значение |
|---|---|
| V½ активации | **−30 мВ** (диап. −25…−35) |
| Активационная крутизна k | **~6 мВ** (5–8) |
| Активация τ | **14.6 мс @V½**, exp-спад k=30.1 мВ (Zerr 1998) |
| γ (унитарная) | ~9–14 пС |
| Инактивация | нет (C-type очень медленная, секунды) |
| Роль | реполяризация, задержка первого спайка |

**Kv2.1 (KCNB1)** — ДРУГОЙ канал: высокопороговый (V½≈0 мВ), медленный (τ~15–100 мс),
sKDR/адаптация, U-type инактивация. Исправлено (2026-09-22): KV_DR = Kv1.1 (KCNA1);
Kv2.1 = отдельный модификатор MOD_KV21.

## Выбор для модели

**Kv1.1 (KCNA1)** — низкопороговый быстрый KDR, соответствует текущей роли
(быстрая реполяризация) и V½=−30 мВ.

## V-зависимость τ (доработано 2026-09-22)
- τ_m(V) = 14.6·exp(−(V−V½)/30.1) мс (Zerr 1998: human Kv1.1, τ_V½=14.6 мс, k=30.1 мВ).
- Clamp [0.3, 200] мс для стабильности. При спайке (V=+20) τ≈2.8 мс, при покое (−60) τ≈39 мс.
- `kv_dr_m_tau(V, V_half)` в modifier_helpers.h — единый источник (fallback + плагин).

## Mean-field оговорка

- **Парадигма Ohm** (не GHK): voltage-gated K⁺ канал с чётким E_K → I = g·m·(V−E_K),
  как DIN_NAK (125) — HH α/β по Sautois. GHK+магия-P — неверная парадигма для KDR.
- **Один m-гейт** (Больцман) вместо n⁴ — упрощение; тетрамерная кооперативность
  свернута в крутизну k.
- **Нет инактивации** — C-type слишком медленная для спайка.
