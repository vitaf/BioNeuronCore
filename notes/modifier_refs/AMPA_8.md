# AMPA (8) — ионотропный глутаматный рецептор

**Тип:** MOD_NT_RECEPTOR_AMPA (8).
**Роль:** быстрый возбуждающий постсинаптический ток (EPSC).
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **Traynelis et al. (2010)** *Pharmacol Rev* 62:405 — GluA2-содержащий: P_Ca≈0 (Q/R-редактирование), E_rev≈0 мВ.
- **Nature 2025** (GluA2 континуум) — P_Ca/P_Na ≈ 0.06, P_Na:P_K ≈ 1:1.

## Модель (GHK, катионная ветвь)

```
I = P_max · density · r · GHK(P_Na:P_K:P_Ca)
r = активация (tau_rise=0.5 мс, tau_decay=3.0 мс)
P_Na:P_K:P_Ca = 0.5:0.5:0.0   → E_rev ≈ 0 мВ
```

## Что исправлено (2026-08-19)

1. **P_Na:P_K 0.7:0.3 → 0.5:0.5** (E_rev +17 → 0 мВ).
2. **Parity-баг:** плагин mod_08 (EC50=0.01, tau=1.0/5.0) ≠ fallback (EC50=0.5, tau=0.5/3.0).
   Приведён плагин к fallback.
3. **Single-source:** параметры вынесены в units.h (AMPA_*).

## ЗНАКОВЫЙ БАГ ionotropic_ghk_current (общий, b7caf1d)

`ghk_current_nA` — «наружу-положительный». Катионная ветвь ошибочно `I_total = I_Na − I_K`
и транспорт Na/Ca `+=` вместо `-=`. Исправлено на `I_Na + I_K` / `-=`.
До: ток = |Na_in| + |K_out| (не реверсировал). После: |Na_in| − |K_out| (реверс при E_rev).
