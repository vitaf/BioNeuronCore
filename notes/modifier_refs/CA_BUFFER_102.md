# CA_BUFFER (102) — Ca²⁺-буфер (парвальбумин-подобный)

**Тип:** MOD_CA_BUFFER (102). Категория Ca²⁺/K⁺/Cl⁻ гомеостаз.
**Роль:** обратимое связывание Ca²⁺, сглаживает Ca²⁺-транзиенты, защищает от Ca-перегрузки.
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **Schwaller (2010)** *Cold Spring Harb Perspect Biol* 2:a004051 — цитозольные Ca²⁺-буферы.
- **Baimbridge et al. (1992)** *Trends Neurosci* 15:303 — кальций-связывающие белки (парвальбумин, кальбиндин).

## Модель (обратимое связывание, без тока)

```
Ca²⁺ + B ⇌ CaB
d[CaB]/dt = k_on·[Ca]·B_free − k_off·[CaB],   B_free = B_total − [CaB]
B_total = B_total_ref(150µM) · density     ← density масштабирует ЁМКОСТЬ
K_d = 500 нМ, k_on = 0.1 мМ⁻¹мс⁻¹, k_off = K_d·k_on = 5e-5 мс⁻¹
return 0.0  // не электрогенный
```

## Что исправлено (2026-08-19)

**density масштабировал СКОРОСТЬ** (`dCa_bound·density`), что меняло кажущееся сродство
K_d_eff = K_d/density и НЕ масштабировало ёмкость. Теперь density масштабирует **ЁМКОСТЬ**
B_total (количество белка); k_on/k_off — фиксированные свойства молекулы, а абсолютная
скорость связывания растёт через B_free (больше белка → больше свободных сайтов).

## Тесты (test_ca_buffer.cpp, 4 cases / 4 ассертов)

return 0, равновесие Ca_bound = B_total·Ca/(Ca+K_d), ёмкость ∝ density, буферизация снижает свободный Ca²⁺.

## Замечание

Буфер медленный (τ ~ 1/(k_on·[Ca]+k_off) ~ секунды при µM Ca) — парвальбумин-подобный.
Это быстрая vs медленная буферизация — отдельный слой, не моделируется (mean-field).
