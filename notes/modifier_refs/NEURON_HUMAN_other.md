# NEURON_HUMAN — Прочие (аудит, группа 15)

**Источник:** агент (WebSearch). 8 типов: MedialSeptum, LateralSeptum, BNST, SubfornicalOrgan,
OVLT, PancreaticBetaCell, PancreaticAlphaCell, EnterochromaffinCell.

> ⚠️ **ОГОВОРКА О ЧЕЛОВЕЧЕСКИХ ДАННЫХ (маркер):**
> Прямой электрофизиологии живых человеческих нейронов ПОЧТИ НЕТ. Основной источник —
> грызуньи срезы + человеческий транскриптом/протеом. Для каждой плотности помечаем источник.
> β/α-клетки и EC-клетки — эндокринные (не нейроны), поэтому морфология = сома без дендритов/аксона.

## Формула калибровки плотности (система)
`density = G·10/(γ·Po)` — G (мС/см²), γ (пС) → density (каналов/мкм²).
⚠️ Для V-гейтированных каналов Po передаётся в `open_prob` модификатора и НЕ входит в density
(иначе двойной учёт). Формула `…/(γ·Po)` — для leak/persistent (K2P/NaP/KATP/TRPV), сверять с реализацией.

## 1. MedialSeptum (медиальная перегородка) — theta-пейсмейкер
- **NT:** GABA (PV⁺, theta-rhythmic — ГЛАВНЫЙ пейсмейкер); есть также холинергические (ACh) и глутаматергические.
- **Роль:** септо-гиппокампальный генератор theta (4–12 Гц).
- **Каналы:** **HCN1+HCN2 (Ih)** — маркер theta-GABAergic (HCN⁺ → ритмичный фазово-связанный спайк);
  **Kv7/M (KCNQ2/3)** — M-резонанс на theta; **T-Ca (Cav3.x)** — рибаунд; Na, KDR, KCa.
- **RMP/осцилляции:** прямого RMP нет; модель E_leak −65 мВ, E_K −85 мВ. GABAergic-тип: короткий ПД,
  короткий AHP, time-dependent rectification/rebound, 4–13 спайков/цикл theta; холинергический — 1–3/цикл. Theta 4–12 Гц.

## 2. LateralSeptum (латеральная перегородка)
- **NT:** GABA (основной), часть глутамат.
- **Каналы:** Na (fast); **Ca высокопороговый** (slow spike, TTX-резистентный) + **Ca низкопороговый**
  (де-инактивируется гиперполяризацией ≤ −75 мВ, 100–150 мс); **два Ca²⁺-зависимых K-тока** —
  ранний sAHP (апамин/тубокурарин-чувствит. = SK) и поздний sAHP (адаптация); KDR; **Ih** (Cs⁺-чувствит.
  anomalous rectification, Ba²⁺-нечувствит.).
- **RMP:** −60.2±4.8 мВ (дорсолатерально), −59.8 (промежуточно), −56 (медиально); R_in 63–83 МОм; τ_m 11–18 мс.

## 3. BNST (bed nucleus stria terminalis)
- **NT:** GABA (основной), часть глутамат (антеролатеральный BNST ALG).
- **Каналы (Hammack 2007):** **Ih** (Type I, II — sag); **I_T (T-Ca)** (Type II — burst);
  **I_K(IR) (Kir)** (Type III — нет sag); **I_A (Kv4.2/Kv4.3 + KChIP1-4)**; **I_NaP**.
  I_A ↔ I_T оппозитно задают латентность/длительность/частоту ПД и дендритный back-propagation.
- **RMP:** (нужна лит-ра); Type I/II/III различаются по Ih/IT/IK(IR); burst = I_T.

## 4. SubfornicalOrgan (SFO) — осмосенсор
- **NT/гормон:** нейроны глутаматергические (+AT1-ангиотензиновые), → вазопрессин/жажда.
- **Сенсорная цепь (двухклеточная):** **Na_x (SCN7A) в глии** (сенсор [Na⁺]) → лактат/EETs → ↑H⁺ →
  **TRPV4⁺ нейроны** → жажда. **TRPV1⁺ нейроны** — механоосмо-сенсор (сморщивание при гиперосмолярности).
  **Kir4.1** — глиальный K⁺-буфер (астроцитарные endfeet). K-каналы нейронов: **Kv1.4, Kv3.4, Kv4.1/4.2/4.3** (I_A).
- **RMP:** (нужна лит-ра); гиперосмолярность → деполяризация + firing.

## 5. OVLT (organum vasculosum lamina terminalis) — первичный осморецептор
- **NT/гормон:** нейроны (AT1a⁺), → SON/PVN (вазопрессин), жажда. **Интринсивный осмометр.**
- **Каналы:** **TRPV1 — необходим** для интринсивной осморецепции (гипертоничность → сморщивание →
  механическое открытие → inward cation ток → деполяризация → ПД); TRPV4 присутствует, но НЕ необходим
  для гипертоничности; **ENaC/бензамил-чувствит.** — NaCl-сенсинг (не маннитол); **ASIC1a** — ниже
  по SLC9A4/NHE4 [Na⁺]-сенсору; **Na_x (глия), Kir4.1 (глия)** — как в SFO.
- **RMP:** гиперосмолярность → деполяризация + ↑ПД.

## 6. PancreaticBetaCell — инсулин, Ca-осцилляции
- **Гормон:** инсулин. Эндокринная клетка (сома без дендритов).
- **Каналы:** **KATP (Kir6.2/SUR1)** — глюкозный сенсор, задаёт RMP; **Cav1.3 (L-type)** — Ca-осцилляции
  (преимущественно сопряжён с глюкозо-индуцированными [Ca²⁺]ᵢ); **BK (KCa1.1)** — реполяризация ПД;
  **SK3 (KCa2.3)**; малый Nav; KDR (Kv2.1).
- **RMP/осцилляции:** −70 мВ (глюкоза <5 мМ), −50…−40 мВ (высокая глюкоза); burst ПД на плато
  (6–16 мМ глюкозы), порог ПД > −40 мВ. KATP активность сама осциллирует (метаболич. обратная связь Ca²⁺→KATP).

## 7. PancreaticAlphaCell — глюкагон
- **Гормон:** глюкагон. Эндокринная клетка (сома без дендритов).
- **Каналы:** **T-Ca (Cav3.x)** (инактивация V½ −45 мВ); **L-Ca** (нифедипин-чувствит. 50%,
  ω-conotoxin GVIA/N-type 25%); **TTX-чувствит. Na** (инактивация V½ −47 мВ, пик 200 пА @+10 мВ);
  **KATP (Kir6.2/SUR1)** — задаёт RMP, защищает от деполяр.-инактивации; **A-type K** (4-AP-чувствит.,
  инактивация V½ −68 мВ); KDR (TEA-чувствит., активация > −20 мВ).
- **RMP/ПД:** RMP < −50 мВ; ПД ~1 Гц (без глюкозы), upstroke 5 В/с, пик +1 мВ; глюкоза 20 мМ ингибирует.
  Диапазон генерации ПД **−60…−35 мВ**; избыточная деполяризация → инактивация Na/T-Ca → остановка.

## 8. EnterochromaffinCell — серотонин (5-HT)
- **НТ/гормон:** **5-HT (серотонин)** — >90% серотонина тела. Эндокринная эпителиальная клетка.
- **Каналы:** **NaV1.3 (SCN3A)** — базальная сторона, генерация ПД (fast inact., блок ICA-121431);
  **Piezo2** — механотрансдукция (сила → ток → Ca²⁺ → 5-HT); **L-type Ca** (нифедипин) + **N-type**
  (ω-conotoxin GVIA) — стимул-секреция; **RyR3 + IP₃R** — Ca-депо, амплификация механич. Ca²⁺-входа.
  Спонтанные burst ПД.
- **RMP:** (нужна лит-ра); электрически возбудима, спонтанные burst.

## Главные расхождения / чего нет в системе
1. **KATP (Kir6.2/SUR1)** — НЕТ модификатора (β/α-клетки без него нереалистичны). Нужен новый ATP-зависимый K-канал (γ~60–80 пС, ATP-ингибирование).
2. **TRPV1 / TRPV4 / ENaC / ASIC1a / Piezo2** — НЕТ модификаторов (осмосенсоры SFO/OVLT и EC-механосенсор не собрать).
3. **Na_x (SCN7A) и Kir4.1** — глиальные сенсоры (не входят в нейрональный состав; Kir4.1 можно из Kir-семейства отдельным γ~22 пС).
4. **Kv7/M-ток** — отдельного модификатора нет (в thalamus.md уже отмечено γ=9 пС).
5. Группа «прочие» в `neuron_library.h` — вероятно заглушки; состав/локализацию задавать по этим таблицам.

### Ключевые находки
1. **VEN** — электрофизиологии нет вообще (только транскриптом + R_in). Аудит по транскриптому.
2. **ipRGC** — фотопроводимость субтип-специфична (M1=TRPC6/7, M2=TRPC+T-type, M4=K-утечка). Один «средний» ipRGC некорректен.
3. **Pinealocyte** — Cav1.4 НЕ подтверждён; L-type = Cav1.3, T-type = Cav3.1 (норадреналин-зависимый).
4. **Pericyte** — Kir2.2 (не Kir2.1), RMP −40; BKCa γ=228, KV1 V0.5 сдвиг +18.5 мВ.
5. **Choroid plexus** — RMP задаёт Kir7.1 (γ 0.05 пС — экстремально малый, нужен отдельный модификатор).
6. **EC-клетки** — Nav1.3 критичен (не Nav1.7/1.8), Piezo2 механо.
