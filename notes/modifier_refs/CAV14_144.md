# Cav1.4 (CACNA1F) — L-type Ca²⁺ канал фоторецептора

Тип: **MOD_CAV14 (144)**. GHK Ca²⁺ (z=2), γ=4 пС. Градуальный sustained-выброс (без CDI).

## ⚠️ Почему в литературе «плывёт» V½ (корень расхождения)

Измеренный V½ активации Cav1.4 различается в источниках до ~35 мВ. Это НЕ ошибка — три фактора:

| Фактор | Условие | V½ / Vact |
|---|---|---|
| **Носитель заряда** | 2 мМ Ca²⁺ (физиологичный) | **−10…−17 мВ** |
| | 20 мМ Ba²⁺ | −3…+2 мВ |
| | 100 мМ Ba²⁺ (single-channel) | −19 мВ |
| **Сплайс-вариант** | полноразмерный (с CTM/экзон 47) | деполяризован, слабый CDI |
| | Δex47 (без CTM) | гиперполяризован + сильный CDI |
| **Протокол** | ramp | −17 мВ |
| | step | −10 мВ |

> **«−40 мВ» (McRory 2004) — это ПОРОГ начала активации, а НЕ V½.** Формулировка «activates near −40 mV» = начало активации, не полумаксимум. Реальный V½ голого полноразмерного Cav1.4 (2 мМ Ca²⁺) ≈ **−15 мВ**.

## Механизм: CTM/ICDI ингибирует активацию, CaBP4 снимает ингибицию

```
Cav1.4 C-конец:   [EF-hand]—[Pre-IQ]—[IQ]—[ICDI]—[CTM (экзон 47)]
                                              │
   ICDI (интринсивно):  убирает CDI  ──────────┤  ← поэтому Cav1.4 «без CDI»
   CTM (интринсивно):   ИНГИБИРУЕТ активацию ───┤  ← V½ деполяризованно (голый V½ ≈ −15 мВ)
                                                │
   CaBP4 ──связывает──▶ IQ ──мешает──▶ ICDI ──▶ СНЯТИЕ ингибиции:
                                                │     V½ −10 мВ + доступность ×5
                                                ▼
```

## Параметры (литературные)

| Параметр | Значение | Источник |
|---|---|---|
| γ (single-channel) | **4 пС** (1–4 пС) | Doering 2005, Biophys J 89:3042 |
| CDI | **отсутствует** (ICDI-домен) | McRory 2004 J Neurosci 24:1707; Shaltiel 2012 |
| VDI | **медленная** (секунды), «highly resistant» | McRory 2004 |
| V½_bare (Ca²⁺, полн.) | **−15 мВ** ⚠️ НЕ чётко (−10…−17, зависит от протокола/сплайса) | McRory 2004; Peloquin 2008 |
| k (slope) | 7 мВ ⚠️ НЕ чётко | по аналогии с L-type |
| τ_m | 2 мс ⚠️ НЕ чётко (τ_open ≈ 3 мс, Doering) | — |
| ΔV½ (CaBP4) | **−10 мВ** | Shaltiel 2012, J Biol Chem 287:36312 |

> **Про «×5»:** Shaltiel 2012 измерял «Ca²⁺-вход ~×5 при −40 мВ» — это **СЛЕДСТВИЕ сдвига V½** («as a consequence of the hyperpolarizing shift»), а НЕ отдельный параметр. В модели boost НЕ закладывается — рост входа выходит из сдвига V½ естественно.

## Модель (связь с CaBP4 — [[CABP4-145]])

```
bound      = segment_cabp4_bound(s)          // 0…1, доля Cav1.4, связанная CaBP4
V½_eff     = CAV14_VHALF_BARE + CAV14_CABP4_DVHALF · bound   // −15 − 10·bound
open_prob  = m²                                              // сдвиг V½ уже учтён в Vhalf

```

Плотность: `density = G·10/γ` (гейтированный канал; эффект CaBP4 — отдельно, НЕ в density).

## Статус
