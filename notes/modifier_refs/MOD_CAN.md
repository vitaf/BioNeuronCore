# MOD_CAN — CAN (TRPM4/TRPM5) Ca²⁺-активируемый неселективный катионный канал

**Тип:** MOD_CAN (152) — новая изоформа (задача 8).

## Литература
- **TRPM4/TRPM5**: Ca²⁺-активируемый НЕселективный катионный канал — проводит Na⁺/K⁺ (моновалентные), **НЕ проводит Ca²⁺** (Ca²⁺ — активатор, не переносчик).
- **γ = 25–35 пС** (неселективный моновалентный).
- **Ca²⁺-зависимый Po** (Hill n=2, EC50 ≈ 0.5 µM) — внутриклеточный Ca²⁺ открывает.
- Voltage-independent, E_rev ≈ 0 мВ (Na/K смесь).
- Роль: инспираторный драйв-потенциал pre-BötC (до 96% нейронов, Pace 2007; Crowder 2007 PMID 17599963).

## Молекулярные константы (для модификатора)
- γ = 30 пС; P_Na:P_K = 1:1 (неселективный моновалентный); Ca²⁺-зависимый Po = Ca²/(Ca²+Kd²), Kd = 0.5 µM.
- GHK-поток: mixed Na⁺/K⁺ (два ghk_current_pA с долями 0.5/0.5).
- НЕТ Ca²⁺-проводимости (TRPM4/5 не Ca-проводящий).

## НЕ нужны для модификатора (клеточный уровень, этап 6)
- G (мС/см²) — density = G·10/(γ·Po).
- Применение: RESP_CPG (инспираторный драйв), гипоталамические нейроны (OT/VP sDAP/fDAP).
