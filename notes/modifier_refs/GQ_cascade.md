# Gq → PLC → IP3 + DAG → IP3R/PKC каскад (справочные данные)

Категория аудита: **#10 (Gq-рецепторы)** + IP3R (127) + PKC (137) + Kv7/M-ток (112).
Дата: 2026-08-21.

## Цепочка

```
Gq-рецептор (5-HT2A/2B/2C, α1A/α1B, M1/M3/M5, mGluR1/5, H1)
  → Gαq-GTP → PLCβ → PIP2 → IP3 + DAG (1:1, всегда вместе)
      ├─ IP3 (цитозоль) → IP3R (Li-Rinzel) → Ca²⁺ из ЭПР
      └─ DAG (мембрана) + Ca²⁺ → PKC (C1 + C2) → фосфорилирует Kv7/KCNQ → подавление M-тока
```

## Ключевые факты (литература)

- **IP3 + DAG всегда вместе (1:1)**: PLCβ гидролизует PIP2 → IP3 + DAG — два продукта одной
  реакции. IP3 без DAG не бывает. → моделируются **совместно** (один `MOD_PLC_IP3_DAG`).
- **DAG бывает без IP3**: через PLD (PC→PA→DAG) или PC-PLC — другой путь (не Gq), будущий модификатор.
- **PKC — отдельная киназа**: классическая (α/β/γ) требует **DAG (C1-домен) + Ca²⁺ (C2-домен)**;
  активация = совместное связывание обоих (мультипликативно). → **отдельный `MOD_PKC`**.

## Параметры (units.h)

| Параметр | Значение | Обоснование |
|---|---|---|
| PLC продукция IP3 | 0.0005 мМ/с (0.5 µM/с на полный Gq) | до ~µM IP3 |
| IP3 деградация τ | ~1 с | IP3-5-фосфатаза |
| DAG деградация τ | ~2 с | DAG-киназа |
| PKC K_d DAG | 0.1 (норм.) | C1-домен, µM-аффинность (классич. ниже novel) |
| PKC K_d Ca²⁺ | 0.5 µM | C2-домен классической PKC |
| Kv7 подавление | до −80% | PKC-фосфорилирование KCNQ (M-ток) |
| Gq десенситизация τ | ~70 с | GRK/β-аррестин (как Gs/Gi) |

## Калибровка vs молекула

- **Молекула**: PLC (продукция IP3+DAG), PKC K_d (DAG/Ca²⁺), IP3R K_IP3 (0.13 µM), кратность Kv7.
- **Клетка**: density модификаторов (сколько Gq-рецепторов / PLC / PKC экспрессирует клетка).
