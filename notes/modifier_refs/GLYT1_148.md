# GlyT1 (SLC6A9) — глиальный транспортер глицина

Тип: **MOD_GLYT1 (148)**. Na⁺/Cl⁻-сопряжённый транспортер (SLC6, LeuT-подобный фолд). Заменяет tau_clearance для глицина.

## Биология
- Глиальный транспортер глицина (астроциты) — клиренс глицинергических синапсов, регуляция глицина у NMDA-рецепторов.
- Семейство **SLC6** (Na⁺/Cl⁻-зависимые), тот же фолд что GlyT2/GAT1/GAT3, но другой ген.

## Стехиометрия и кинетика (литература)
| Параметр | Значение | Источник |
|---|---|---|
| Стехиометрия | **2 Na⁺ + 1 Cl⁻ + глицин** (внутрь), net +1 | Erdem 2019 |
| Глицин EC50 | **≈ 44.7 ± 2.4 µM** | Erdem 2019 JGP 151:1035-1050 |
| Локализация | астроциты (глия) | |

## Модель (shared-хелпер)
```
захват = I_max·density·area·(Gly/(Gly+K_m))     // Michaelis-Menten
за цикл: 2 Na⁺ внутрь + 1 Cl⁻ внутрь + 1 глицин внутрь (net +1)
I = +1 заряд/цикл (деполяризующий)
```

## Отличие от GLAST (SLC1)
- GLAST = SLC1: 3 Na⁺ + H⁺ + Glu / **1 K⁺ наружу** (K⁺-контртранспорт).
- GlyT1 = SLC6: 2 Na⁺ + **1 Cl⁻ внутрь** (Cl⁻-котранспорт, без K⁺).

## Статус
✅ Стехиометрия 2 Na⁺/1 Cl⁻, глицин EC50≈44.7 µM — твёрдо (Erdem 2019). ⚠️ K_m в отн.ед. (GLYT1_K_M_REL=30) — калибровка (задача #20). Нейрональный GlyT2 (SLC6A5) — не смоделирован.
