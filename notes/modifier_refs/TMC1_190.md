# TMC1/TMC2 — MET канал стереоцилий волосковых клеток

**Тип:** механочувствительный ионный канал (mechanoelectrical transduction).

## Биофизический паспорт
| Параметр | Значение | Источник |
|---|---|---|
| γ | **50–110 пС** (нативный, тонотопический); гетерологичный 18–24 пС | Beurg 2014; PNAS 2022, 36191207 |
| Po покой | **~10–15%** (натяжение tip-link) | Corey & Hudspeth 1983 |
| Активация | механо (сдвиг пучка стереоцилий), НЕ вольт-зависим | Ricci 2002, 11929895 |
| Адаптация fast | **τ 0.3–5 мс** (Ca²⁺-зависимая) | Ricci 2002; Corns 2014 |
| Адаптация slow | **τ 10–30 мс** (myosin-1c/7a) | J Neurophysiol 2003 |
| Ингибиция | DHS 14 µM, амилорид 24 µM, Gd³⁺ 10 µM | Ricci 2002 |
| Кинетика | τ_act 30–400 µs | Ricci 2002 |
| Селективность | **P_Ca/P_Na ≈ 3.8** | Beurg 2015, 25389310 |
| Локализация | стереоцилии (верхушки), IHC + OHC | Pan 2013, 23871232 |

## Реализация (наша модель — GHK/ионы)
- TMC1 = ионный канал-модификатор (MOD_TMC1).
- Механо-стимул через `state[4]` (сдвиг пучка, 0..1) — VirtualBody-мост.
- Po = базальная 10% + Hill(стимул); адаптация fast (Ca²⁺) + slow (myosin).
- GHK: P_Ca:P_Na = 3.8:1 (γ=80 пС, среднее 50–110).
