# Аудит γ ионотропных рецепторов (убрать GHK_P_PER_CM_S суррогат)

**Задача #83 (MCP).** Все ионотропные рецепторы сейчас на суррогате
`GHK_P_PER_CM_S=1e-4` с **относительным** P_max (1.0/0.5/0.3) — это не
одномолекулярная концепция. Цель: перевести на `ghk_partial_P(γ, ...)` с
**абсолютной** одноканальной проводимостью γ (пС) из литературы.

По Modifier Audit Method: литература → этот справочник → сверка честности →
согласование → фикс → тест → маркер. **Каждая γ — с источником.**

## Соотношения проницаемостей (P_Na:P_K:P_Ca) — определяют E_rev

Текущие в `ionotropic_ghk_current` заданы параметрами `P_Na_ratio:P_K_ratio:P_Ca_ratio`
per-рецептор (в callers). При миграции на `ghk_partial_P` — сохранить текущие
соотношения (они честные, из литературы по селективности), менять только
**масштаб** (P_max → γ).

## Перекалибровка (ожидаемая)

P_max (относит., норм. к AMPA=1.0) → γ (абсолют.) меняет **магнитуду** тока
per-рецептор (AMPA ×1 → γ=8; NMDA ×1 → γ=50 → NMDA станет ~6× сильнее AMPA).
Это перекалибровка (как этап 2 K2P), НЕ «тот же ток». Плотности рецепторов
переаудируются после. Согласовать с пользователем до фикса.
