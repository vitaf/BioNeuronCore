# KCC2 (100) — K⁺-Cl⁻ котранспортёр

**Тип:** MOD_KCC2 (100). Категория Ca²⁺/K⁺/Cl⁻ гомеостаз.
**Роль:** нейрон-специфичный Cl⁻-экструдер, задаёт низкий [Cl⁻]i → гиперполяризующее GABA/глицин.
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **Payne, Stevenson & Donaldson (1996)** / **Payne (1997)** — клонирование KCC2 (SLC12A5).
- **Rivera et al. (1999)** *Nature* 397:251 — KCC2 делает GABA гиперполяризующим при созревании.
- **Gamba (2004)** *Physiol Rev* — электронейтральные катион-хлорид котранспортёры, K_m(Cl⁻_i)≈6.8-7.2 мМ.
- **Staley & Proctor (1999)** — V_max ≈ 5-6 мМ/с (K⁺).

## Модель (электронейтральный поток)

KCC2 электронейтрален (1 K⁺ : 1 Cl⁻, нетто заряд 0) → НЕТ тока, только поток.

```
J [моль/с] = V_max · density · area · f_K · f_Cl · driving
f_K = K_i/(K_i + K_m),  K_m = 6.5 мМ
f_Cl = Cl_i/(Cl_i + K_m), K_m = 6.5 мМ
driving = 1 − [K]o[Cl]o / ([K]i[Cl]i)   // термодинамическая движущая сила
   >0 → выводит K+Cl; <0 → вводит; =0 → равновесие [K]i[Cl]i = [K]o[Cl]o
Δ[K]i = Δ[Cl]i = −J·dt/(NA·vol)   // чистый поток, не фальшивый ток
return 0.0  // электронейтральный
```

- V_max = 5 нмоль/(см²·с) (литература 1-10).
- Термодинамическая движущая сила (обратимый котранспорт): KCC2 останавливается при
  [K]i[Cl]i = [K]o[Cl]o, а не гонит K+Cl бесконечно. Высокий внеклеточный K⁺ тормозит
  выброс через ту же движущую силу (растёт [K]o[Cl]o).

## Что исправлено (2026-08-19)

1. **Магический v_max=0.0008** («mM/ms/cm²», противоречил BIOREF «1-10 нмоль/см²/с») → **V_max=5 нмоль/см²/с**.
2. **Транспорт через charge_per_mole (ток)** → **чистый поток** Δc = J/vol (KCC2 электронейтрален, ток концептуально неверен).
3. **Эмпирический trans_inhib** (`1 − K_o/(K_o+0.5)`) → **термодинамическая движущая сила**
   (`driving = 1 − [K]o[Cl]o/([K]i[Cl]i)`, обратимая, 2026-09-13). До фикса KCC2 гнал K+Cl
   наружу бесконечно (без равновесия), из-за чего K_i/Cl_i дрейфовали −0.75 мМ/с в покое MN.
   Теперь останавливается при [K]i[Cl]i = [K]o[Cl]o.

**Важная находка:** прежний v_max=0.0008 давал ~1.7e-3 мМ/с — KCC2 фактически не работал
(Cl⁻ не выбрасывался). Теперь ~8 мМ/с (литературный диапазон 5-6 мМ/с). Это значительное
ускорение Cl⁻-динамики — повлияет на CPG, но плотность (0.8) перекалибруется в клеточных задачах.

## Одномолекулярный перевод (отложен, 2026-09-22)

Точных литературных turnover (k_cat) и плотности (молекул/µm²) для KCC2 НЕ найдено
(только STORM нанокластеры без абсолютных значений). **Вариант A (выбран):** оставлен
эмпирический V_max (Staley & Proctor 1999) — не суррогат-молекула, а честный поток.

**Вариант B (запасной, при проблемах в нейронах):** `flux = N·k_cat·f_K·f_Cl·driving·dt/N_A`,
k_cat = 1000 с⁻¹ (ориентир — NKCC1 forward rate 1002 с⁻¹, Biophys J), density = 3000/µm²
→ V_max ≈ 0.5 нмоль/см²/с (~10× ниже текущего 5).
