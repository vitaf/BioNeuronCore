# CaBP4 (calcium-binding protein 4) — модулятор Cav1.4

Тип: **MOD_CABP4 (145)**. Белок-модулятор (НЕ канал, ток = 0). Снимает ингибицию CTM/ICDI на Cav1.4.

## Биология

CaBP4 — CaM-подобный Ca²⁺-связывающий белок, специфичный для **синаптических терминалей фоторецепторов** (и волосковых клеток). Два глобулярных домена (N-lobe + C-lobe), в каждом по 2 EF-hand; 2-й EF-hand N-lobe — нефункциональный.

**Механизм (Shaltiel 2012, J Biol Chem 287:36312):**
1. CaBP4 связывает **IQ-мотив** C-конца Cav1.4.
2. Мешает связыванию **ICDI-домена**.
3. Снимает ингибицию ICDI на вольт-зависимую активацию.
4. Итог: **ΔV½ = −10 мВ** (enhanced activation) + **reduced VDI** (вторичный).

## Эффект на Cav1.4 (литературные числа)

| Величина | Без CaBP4 | С CaBP4 | Δ | Источник |
|---|---|---|---|---|
| V½ активации | −5.3 ± 1.9 мВ | −15.4 ± 1.2 мВ | **−10 мВ** | Shaltiel 2012 |
| Vmax | +17.2 ± 1.3 мВ | +7.8 ± 1.6 мВ | — | Shaltiel 2012 |
| Ca²⁺-вход при −40 мВ | 1× | **5×** | ×5 (следствие сдвига V½) | Shaltiel 2012 |

> **Два эффекта CaBP4** (Park 2014, J Biol Chem 289:31262): (1) **enhanced activation** — сдвиг V½ на −10 мВ (доминирует при −40…−45 мВ); (2) **reduced VDI** — замедление инактивации (вторичный, на потенциалах фоторецептора пренебрежим). «×5» = net availability = в основном сдвиг V½. В модели boost НЕ закладывается отдельно.

> Примечание: абсолютные V½ здесь (−5.3 мВ) — в HEK293 + 20 мМ Ba²⁺ (деполяризованные условия). **Сдвиг ΔV½ = −10 мВ — относительный, робастный** (не зависит от носителя/условий). В модели абсолютный V½ голого Cav1.4 берём −15 мВ (Ca²⁺, см. [[CAV14-144]]).

## Зависимость от экзона 47

Эффект CaBP4 на активацию **требует экзона 47/CTM**: у Δex47 (без CTM) CaBP4 подавляет CDI, но НЕ сдвигает активацию. В модели берём полноразмерный Cav1.4 (с CTM) → CaBP4 сдвигает V½ и даёт boost.

## Модель (модулятор, ток = 0)

```
state[0] = bound   // доля Cav1.4, связанная CaBP4; насыщается к 1 (изобилен, высокое сродство)
bound    += (1 − bound) · dt/τ_bind      // τ_bind ~ 1 мс (белок-белок)
return 0.0f                               // НЕ канал — мембранного тока нет
```

Cav1.4 читает `segment_cabp4_bound(s)` и применяет сдвиг+boost (см. [[CAV14-144]]).

## Роль в клетке

Фоторецептор (PINEAL): CaBP4 + Cav1.4 → тонический Ca²⁺-вход в темноте → тонический выброс глутамата. Без CaBP4 (knockout) → CSNB2-подобный фенотип (нарушена синаптическая передача).

## Статус
✅ ΔV½=−10 мВ, механизм (IQ/ICDI, структурно подтверждён Park 2014), зависимость от экзона 47 — **твёрдо** (Shaltiel 2012; Park 2014 J Biol Chem 289:31262; обзор Front Mol Neurosci 2012 5:26). τ_bind ~1 мс — оценка (белок-белок, быстрая), НЕ чётко.
