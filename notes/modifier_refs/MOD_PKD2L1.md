# MOD_PKD2L1 — PKD2L1 (TRPP3) Ca²⁺-предпочитающий механосенсор CSF

**Тип:** MOD_PKD2L1 (153) — новая изоформа (задача 8).

## Литература
- **PKD2L1 (TRPP3)**: Ca²⁺-предпочитающий катионный канал CSF-contacting нейронов (Kolmer-Agduhr).
- **γ = 120–200 пС** (гомомер), нативный гетеромер PKD2L1/PKD1L1 80–95 пС.
- **PCa/PNa ≈ 4–6** (Ca²⁺-предпочитающий).
- **Механосенсор CSF-потока**: одиночное открытие 26 пА @−85 мВ → ПД (Sternberg 2018 Nat Commun 9:4004, PMID 30228263).
- Локализация: апикальная ресничка (CSF).

## Молекулярные константы (для модификатора)
- γ = 150 пС (среднее гомомер/гетеромер); P_Ca:P_Na ≈ 5:1 (норм. 0.83:0.17).
- Механо-активация: Po = state[4] (0..1, CSF-поток стимул), по умолчанию 0 (закрыт).
- GHK-поток: mixed Ca²⁺ (z=2) + Na⁺ (z=1).

## НЕ нужны для модификатора (клеточный уровень, этап 6)
- G (мС/см²) — density = G·10/(γ·Po).
- Применение: KolmerAgduhr (CSF-contacting нейрон).
