# CAV13 (1) — L-type Ca²⁺ канал Cav1.3 (CACNA1D)

Бывший `MOD_IONOTROPIC_CA`. Переименован в `MOD_CAV13` (по типу канала, консистентно с MOD_KV42/MOD_KIR/MOD_KNA).

## Источники
- Xu & Lipscombe (2001) *J Neurosci* 21:5944 — **Cav1.3 активируется при гиперполяризованных V** (заметно ниже Cav1.2), неполное дигидропиридиновое ингибирование.
- Koschak et al. (2001) *J Biol Chem* 276:22100 — α1D (Cav1.3) образует L-type каналы, активирующиеся при отрицательных V.
- Striessnig et al. — обзоры L-type (Cav1.2 vs Cav1.3).

## Биологические свойства Cav1.3

| Свойство | Значение |
|---|---|
| Single-channel γ | ~25 пС (L-type, в Ba²⁺) |
| Активация V½ | **−35 мВ** (HVA, но ниже Cav1.2 = −11) |
| Активация k | ~6–7 |
| Инактивация V½ | **−52 мВ** (медленная, τ ~ сотни мс) |
| Инактивация τ | ~100 мс (медл. → плато) |
| CDI | да, слабее Cav1.2 (calmodulin) |
| Роль | **пейсмейкер**: SAN, дофаминовые нейроны SNc (плато/спонтанная ритмика), IHC |

Отличие от Cav1.2 (ID 84): активация при более отрицательных V (−35 vs −11 мВ),
медленная инактивация → поддерживает плато-потенциалы и пейсмейкерную активность CPG dIN.

## Наша текущая реализация (mod_01_ca.cpp)

```cpp
m_inf = 1/(1+exp(-(V+20)/6))      // V½_акт = −20 мВ, k=6
h_inf = 1/(1+exp((V+45)/6.5))     // V½_инакт = −45 мВ, k=6.5
tau_m = 1.5 мс;  tau_h = 80 мс
open = m³ · h
p_gCa = state[2] (default 1.0)    // "проводимость"
P_Ca = p_gCa * density * GHK_P_PER_CM_S   // ← магическая P-шкала
```

## V-зависимость τ (слабо исследована, 2026-08-30)
- τ фиксированы (τ_m=2 мс, τ_h=100 мс). L-type Cav1.3 слабо V-зависим в рабочем диапазоне.
- bell-shaped вариант τ(V) возможен, но НЕ откалиброван лабораторно (требует сверки).
