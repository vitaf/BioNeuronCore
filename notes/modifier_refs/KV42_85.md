# KV42 (85) — Kv4.2 A-type K⁺ канал (KCND2)

## Источники
- Birnbaum et al. (2004) *Physiol Rev* 84:803 — Kv4-семейство транзиентных (A-type) K⁺ каналов.
- Jerng, Pfaffinger & Covarrubias (2004) *Mol Cell Neurosci* 27:343 — физиология/модуляция соматодендритных A-type.
- Migliore et al. (1999) — модель Kv4.2 в CA1 (активация m³).

## Биологические свойства Kv4.2

| Свойство | Значение |
|---|---|
| Single-channel γ | ~5 пС (физиол. K⁺, малопроводящий) |
| Активация V½ | **−10 мВ** (HVA для K⁺, k≈13–15 мВ) |
| Инактивация V½ | **−65 мВ** (быстрая N-type, k≈7–8 мВ) |
| τ_инакт | ~10–30 мс (быстрая A-type) |
| Гейтинг активации | m³ (классич. A-type) |
| CaMKII | фосфорил. Ser-438/459 → ↓ пиковый ток |

Отличие от Kv1.1 (KV_DR 123): Kv4.2 активируется при заметно более деполяризованных V
(−10 vs −30 мВ) и быстро инактивируется (A-type транзиент).

## Наша текущая реализация (kv42_current, hh_biological.cpp + mod_85)

```cpp
Vhalf = state[4] (default −45), k = state[5] (10), P_K = state[2] (0.7);
m: V½=−45, k=10, tau_m=1.5;  h: V½=−65, k=8, tau_h=15;
open = m·h;  CaMKII → P_eff = P_K·(1 − 0.7·phospho);
P_kv = P_eff · density · GHK_P_PER_CM_S;   // ← магическая P-шкала
```

## V-зависимый τ_h (исправлено 2026-08-30)
- Было: τ_h = 15 мс фикс — только быстрая N-type инактивация, без де-инактивации.
- A-type имеет closed-state inactivation: быстрая инактивация при деполяр. (11–19 мс) + медленная
  де-инактивация/recovery при гиперполяр. (131–201 мс).
- Стало: `τ_h(V) = τ_fast + (τ_slow−τ_fast)/(1+exp((V−V_rec_half)/k_rec))`, τ_fast=15, τ_slow=170,
  V_rec_half=−60, k_rec=8 (`kv42_h_tau` в modifier_helpers.h, единый источник CPU+GPU+плагин).
- Источник: Birnbaum 2004 (Physiol Rev 84:803), Jerng 2004 (Mol Cell Neurosci 27:343).
