# CA_LEAK (101) — пассивная Ca²⁺ утечка (TRPC7)

## Источники
Фоновой Ca²⁺-вход в нейронах — через nonselective TRPC-каналы (не отдельный «Ca-leak» канал).
- **TRPC7**: конститутивно активный, nonselective, Ca²⁺-предпочитающий.
- Single-channel **γ ≈ 25–75 пС** (берём 50).
- **P_Ca/P_Na ≈ 2** (Ca²⁺-проницаемость в 2× выше Na⁺).

## Биологические свойства TRPC7

| Свойство | Значение |
|---|---|
| Single-channel γ | ~50 пС (25–75) |
| Селективность | nonselective Na/Ca, P_Ca/P_Na ≈ 2 |
| Конститутивность | да (leak) |

## Наша реализация (ca_leak_current, hh_biological.cpp + mod_101)

```cpp
P_Ca = 0.0015 (state[0]);  P = P_Ca·density·GHK_P_PER_CM_S;  z=2, open=1.0.  // только Ca
```
