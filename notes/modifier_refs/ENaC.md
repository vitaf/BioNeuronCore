# ENaC — эпителиальный Na⁺-канал (солёный вкус тип I) (кандидат)

**Источник:** агент (WebSearch, 2026-09-03).

| Параметр | Значение |
|---|---|
| γ (пС) | **4–5** (Na⁺), 8 (Li⁺); канон. αβγ 4–7 |
| Селективность | Na⁺-селективный; Li⁺>Na⁺≫K⁺ (2:1:0.14) |
| Po | ~0.5 (0.04–0.6) |
| V½ | нет (конститутивно открыт) |
| Блокатор | амилорид IC50 ~100 нМ |

⚠️ Осмосенсор SFO/OVLT — это **Naₓ (SCN7A)**, НЕ ENaC. ENaC — солёный вкус + эпителиальный транспорт Na⁺.

**PMID:** 12087134 (Kellenberger 2002), 8760127 (Matalon 1996).

## Реализация (одномолекулярный рефакторинг 2026-09-21)
- γ=4.5 пС, Po=0.5 (ENAC_PO), амилорид IC50 100 нМ (state[5]).
- `P_single = ghk_single_channel_P(4.5, 1, c̄_Na)` [м³/с] вместо суррогата GHK_GAMMA_PS_TO_P_CM_S.
- Ток Na ×2.68 (c_ref/c̄_Na). Литеральной плотности ENaC нет → density клеточный уровень.
- В neuron_library.h пока не используется (только тип MOD_ENAC 182).
