# PMCA (98) — Ca²⁺-АТФаза плазмалеммы

**Тип:** MOD_PMCA (98). Категория Ca²⁺/K⁺/Cl⁻ гомеостаз.
**Роль:** высокоаффинный, низкоёмкостный выброс Ca²⁺ из цитозоля. 1 Ca²⁺ наружу : 1 ATP.
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **Carafoli (1991)** *Annu Rev Physiol* 53:531 — PMCA: Hill-2, K_m(Ca²⁺) ≈ 0.2–0.5 µM, 1 Ca:1 ATP.
- **Strehler & Zacharias (2001)** *Physiol Rev* 81:21 — изоформы, K_m_ATP ≈ 0.1–0.2 мМ.

## Модель (Hill-2 энзим, вольт-НЕзависимый)

В отличие от Na/K-насоса, PMCA не имеет вольт-зависимого электрогенного шага
(лимитирующий шаг — связывание Ca²⁺ + фосфорилирование, вольт-нечувствительно).
Поэтому честная модель — Hill-2, а НЕ кинетический цикл.

```
I_pump = N · k_cat · f_Ca · f_ATP · e · Δz   (одномолекулярная, 2026-09-22)
N      = density · area[µm²]   (density — КЛЕТОЧНЫЙ параметр, молекул/µm²)
k_cat  = 100 с⁻¹   (BRENDA 9.5-149, физиол. 30-200)
e·Δz   = +2·1.602e-19 Кл   (1 Ca²⁺ = 2 заряда наружу)
f_Ca   = Ca² / (Ca² + K_m²),  K_m = 300 нМ (Hill-2)
f_ATP  = ATP / (ATP + K_m_ATP), K_m_ATP = 0.2 мМ (Michaelis)
return = -I_pump   // электрогенный (+2 наружу) → гиперполяризующий
```

Транспорт: 1 Ca²⁺ наружу, z=2 → `transport = I·dt/(2·cpv)`.

## Что исправлено (2026-08-19)

1. **Знак** — был `+I` (деполяризующий), теперь `-I` (гиперполяризующий).
2. **Магический p_rate=0.015** (комментарий «pmol/cm²/s» = 0.0029 µA/см², расхождение ~100×
   с «0.1–1 µA/см²») → `I_max[µA/см²]·UA_PER_CM2_TO_NA`, I_max = 1 µA/см² (заменено на одномолекулярную).
3. **ATP** — был линейный `ATP_level` (clamp 0..1), теперь Michaelis `ATP/(ATP+0.2мМ)` —
   консистентно с Na/K-насосом ([[PUMP_NAK_7]]).

## Конвенция ATP (партия #6)

`ATP_level` — свойство клетки (Segment), модификатор читает его как [ATP] в мМ
(SI: 1 мМ ≡ моль/м³). f_ATP = ATP/(ATP+K_m_ATP), K_m в мМ. Без клеточного `/5` —
если клетка хранит ATP_level в других единицах — это клеточный фикс, не модификатора.
