# GLAST/GLT-1 (EAAT1/2) — глиальный глутаматный транспортер

Тип: **MOD_GLAST (147)**. Транспортер (НЕ канал). Захват глутамата глией — заменяет `tau_clearance`.

## Биология
- Глутаматный транспортер глии (EAAT). Незрелая глия (головастик) — **GLAST/EAAT1**, медленный захват.
- Захватывает глутамат из синаптической щели, используя Na⁺-градиент.
- **Стехиометрия** (Zerangue & Kavanaugh 1996): **3 Na⁺ + 1 H⁺ + 1 глутамат** (внутрь), **1 K⁺** (наружу) за цикл.
- **Чистый заряд +2** за цикл (электрогенный → входящий ток).
- K⁺-транслокация — лимитирующая стадия; глутамат-связывание лимитирует при низком [Glu].

## Параметры (литература)
| Параметр | Значение | Источник |
|---|---|---|
| Стехиометрия | 3 Na⁺ + 1 H⁺ + Glu (в), 1 K⁺ (наружу) | Zerangue & Kavanaugh 1996 |
| K_m глутамата | **10–20 µM** (GLT-1); GLAST выше | EAAT2 |
| Оборот | **~16 с⁻¹** (GLAST/EAAT1), 10–40 с⁻¹ (GLT-1) | |
| Незрелая глия | GLAST преобладает, медленный захват | Hanson 2015 GLIA |

## Модель (посегментная связь, вариант 1)

```
захват = Vmax · [Glu]cleft / ([Glu]cleft + K_m),   K_m = 15 µM, оборот 16 с⁻¹
Vmax = оборот × N_транспортеров = 16 × (density × area)

за цикл: 3 Na⁺ внутрь + 1 K⁺ наружу (глиальный ионный гомеостаз)
входящий ток: +2 заряда/цикл (электрогенный)
```

**Механизм в коде (2 фазы):**
1. **Шаг 3 (синапс)**: глутамат, высвобожденный синапсом, добавляется в `neurotransmitter[NT_GLUTAMATE]` глиальных клеток **того же сегмента** (посегментная связь). Заменяет `cleft *= exp(-dt/τ)`.
2. **Шаг 1 (ток модификатора)**: глиальный GLAST читает свой `neurotransmitter[NT_GLUTAMATE]`, считает захват (Michaelis-Menten), двигает 3 Na⁺ внутрь + 1 K⁺ наружу, даёт входящий ток (+2). Уменьшает `neurotransmitter[NT_GLUTAMATE]`.

> Лаг 1 тик (захват в шаге 1 читает глутамат предыдущего тика) — приемлемо (клиренс ~мс, тик ~0.1–1 мс).

## Замена tau_clearance
- Для **глутамата**: `cleft_glu` клирится глиальным захватом (НЕ `exp(-dt/τ)`).
- Для остальных NT (глицин/GABA): `tau_clearance` остаётся (глия не захватывает их в этой модели).

## Статус
✅ Стехиометрия 3 Na⁺/1 K⁺, K_m 15 µM, оборот 16 с⁻¹ — твёрдо. H⁺ не моделируется отдельно (входит в чистый заряд +2). ⚠️ Vmax/density — калибровка (этап 6).
