# Gs/Gi → AC → cAMP → PKA каскад (справочные данные)

Категория аудита: **#9 (Gs-рецепторы)** + **#8 (Gi/o → AC-ингибирование)** + кросс-модуляция HCN/L-type Ca²⁺.
Дата: 2026-08-20 (Gi/o-ингибирование добавлено 2026-08-21).

## Цепочка

```
Gs-рецептор (D1/D5/β1/β2/5-HT4/6/7/A2A/A2B/H2/TAAR1)
  → Gαs-GTP → аденилатциклаза (AC): ATP → cAMP   (стимулирует)
Gi/o-рецептор (GABAB/D2/5-HT1A/mGluR2/α2/...) 
  → Gαi-GTP → ингибирует AC (AC5/AC6)            (ослабляет cAMP)
  → [cAMP] (общий пул на сегмент) = f(Gαs − Gαi)
      ├─ напрямую связывает HCN (CNBD) → сдвиг V½ в деполяр. сторону
      └─ активирует PKA (2 cAMP на регуляторную субъединицу) → фосфорилирует Cav1.2
  → PDE гидролизует cAMP → 5'-AMP (терминация)
  → GRK фосфорилирует активированный рецептор → β-аррестин → десенситизация
```

## Gi/o → AC-ингибирование (#8)

- Gαi/o-GTP связывает AC5/AC6 тем же карманом, что Gαs, с nM-аффинностью → ингибирование
  **примерно симметрично стимуляции** (используем k_gi = 1).
- Net AC drive = `AC_BASAL + gs − gi` (clamp ≥ 0) — Gi может опустить [cAMP] ниже базального.
- Это вторая ветка Gi/o-сигнализации; первая (Gβγ → GIRK) — в gi_o_ghk_effect ✅.
- Gi/o-рецепторы уже дают state[0] (G-белковая активация) в gi_o_ghk_effect — camp_pka_step читает его.

## Деактивация vs десенситизация (обе — литературные)

- **Деактивация** (закрытие после снятия агониста): спад [cAMP] определяется PDE-гидролизом.
  PDE4 K_m ~1–4 µM → при базальном [cAMP] 0.1 µM деградация ~линейна по [cAMP], τ_eff ~1–3 с.
- **Десенситизация** (закрытие при продолжающемся агонисте): GRK фосфорилирует активированный
  GPCR → β-аррестин. t½ ~десятки секунд (для многих GPCR ~10–70 с). Используем τ_desens ~70 с.

## Калибровка (клетка) vs молекула

- **Молекула (в аудите, в units.h)**: AC K_m(ATP), PDE K_m(cAMP), PKA EC50/Hill, HCN ΔV½+EC50,
  кратность Cav1.2. Эти константы одинаковы для любой клетки.
- **Клетка (калибровка, НЕ в аудите)**: сколько Gs-рецепторов / AC / PDE экспрессирует клетка
  (density) → амплитуда [cAMP]. Это конфиг нейрона, отдельный этап (задача density-калибровки).
