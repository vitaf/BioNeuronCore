# AQP4 (аквапорин-4) — водный канал (кандидат 186)

**Источник:** Nagelhus 2004 (глия), Yang & Verkman 1997 (single-channel).

## Роль
AQP4 — водный канал (НЕ ионный) на эндофутах астроцитов, Мюллер-глии, эпендиме. Обеспечивает транспорт воды по осмотическому градиенту (CSF-продукция, глимфатика, отёк мозга).

## Параметры
| Параметр | Значение |
|---|---|
| P_f (single-channel) | **24 ± 0.6·10⁻¹⁴ см³/с** (Yang & Verkman 1997, PMID 9195910) — ПОДТВЕРЖДЕНО |
| Макро P_f | 29·10⁻³ см/с (AQP4-ооциты); нативной глии нет → вычислять из плотности × P_f single-channel |
| Тип | водный (не ионный) — осмотический транспорт |
| Локализация | эндофуты (ортогональные массивы, с Kir4.1) |
| Регуляция | не потенциал-зависим (вода), осмотический градиент |

## Как собирались (первоначальный план) → Как сделали

### Изначально планировали (архитектурное расширение)
1. Добавить поле `volume_scale` (float) в `Segment` — переменный объём клетки.
2. Осмотическое давление `Δπ = RT·(Σ[intra] − Σ[extra])`.
3. `J_water = P_AQP4 · area · Δπ`.
4. Обратная связь: объём растёт → ионы разбавляются `c' = c/volume_scale` (шаг 4).
5. **Это влекло BION version bump** (Segment +4 байта, v12→v13) + синк Studio/GPU.

### Сделали (самодостаточный модификатор, БЕЗ BION bump)
Ключевое наблюдение: **ионные концентрации `intra_ions[]` уже сами хранят «разбавление»** — кумулятивный объём не нужен.

`MOD_AQP4` (тип 4, структурный + водный флюкс) самодостаточен:
1. `Δπ = RT·(Σ[intra] − Σ[extra])` — из текущих концентраций.
2. `J_water = P_AQP4 · area · Δπ` — поток воды (положительный = вода входит).
3. Разбавление: `intra_ions[i] *= V/(V + J_water·dt)` (для всех 5 ионов).
4. Самоограничение: вода входит → ионы разбавляются → Δπ падает → поток затухает → равновесие Σ[intra]=Σ[extra].

Это экспоненциальная релаксация первого порядка (обычный Euler-шаг), корректная без кумулятивного объёма. **Segment struct и BION-версия НЕ меняются.**
