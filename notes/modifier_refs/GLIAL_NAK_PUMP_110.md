# GLIAL_NAK_PUMP (110) — глиальная Na⁺/K⁺-АТФаза (α2)

**Тип:** MOD_GLIAL_NAK_PUMP (110). Категория Ca²⁺/K⁺/Cl⁻ гомеостаз.
**Роль:** глиальная Na/K-АТФаза (α2-изоформа), замыкает цикл K⁺-буферинга
(Kir4.1 забирает K⁺ → глиальный синцитий разносит → насос возвращает K⁺).
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- Тот же механизм, что Na/K-АТФаза ([[PUMP_NAK_7]]): цикл Поста–Альберса, 3Na:2K:1ATP, электрогенный +1.
- **α2 vs α3 изоформы** — тот же k_cat (70–80 с⁻¹, Peng/Hertz 2010), выше сродство к K⁺_o (K_m≈1.0 мМ). Различие — в плотности экспрессии (клеточный уровень).

## Модель

Тот же цикл Поста–Альберса (`nak_pump_vnorm`), параметризованный по K_m:
- `nak_pump_vnorm(V, Na_i, K_o, ATP, K_m_Na, K_m_K)`, default (10, 1.5) = α3.
- Глия: K_m_Na=10 мМ, K_m_K=1.0 мМ (выше сродство), k_cat=75 с⁻¹ (как α3). Ток `I = N·k_cat·v_norm·e·Δz`.

## Что исправлено (2026-08-19)

1. **Знак** +I → −I (электрогенный +1 наружу = гиперполяризующий).
2. **Магия 1e-3** → I_max[µA/см²]·UA_PER_CM2_TO_NA (I_max=2 µA/см²).
3. **Hill-3/Hill-2** → цикл Поста–Альберса (V-зависимый).
4. **ATP 5e-8** → NA_K_PUMP_ATP_RATE_NA.
5. **Плагин** πr²L/20 → segment_volume, plugin_segment_area → effective_area (single-source).
