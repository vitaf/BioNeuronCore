# RYR (128) — рианодиновый рецептор (CICR из ЭПР)

**Тип:** MOD_RYR (128). Категория Ca²⁺-гомеостаз (ЭПР).
**Роль:** Ca²⁺-индуцированный Ca²⁺-выброс (CICR) из ЭПР.
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **Keizer & Levine (1996)** — гейтинг RyR: 4-стадийная схема, адаптация w.
- **Tang & Othmer (1994)** — CICR, bell-образная Ca²⁺-зависимость.

## Модель (Keizer–Levine, динамическая адаптация)

```
J = v_rel · w · (1+(c/K_b)³)/(1+(K_a/c)⁴+(c/K_b)³) · ([Ca]ER − [Ca])
K_a = 0.372 µM (Hill-4 активация), K_b = 0.636 µM (Hill-3 ингибирование)
dw/dt = (w∞ − w)/τ_w,  τ_w = 10⁴·w∞ мс
w∞ = (1+(K_a/c)⁴+(c/K_b)³)/(1+1/K_c+(K_a/c)⁴+(c/K_b)²), K_c = 0.057
```

## Что исправлено (2026-08-19)

1. **Hill-3/K_inh=50µM** → полный Keizer–Levine: Hill-4 активация (K_a=0.372µM) + Hill-3 ингибирование (K_b=0.636µM).
2. **Статическая bell-кривая** → динамическая адаптация w (state[]).
3. **p_max магия** → v_rel = 20 с⁻¹ (быстрее IP3R — CICR).
4. **charge_per_mole** → чистый поток (линейный градиент), масса сохраняется.
