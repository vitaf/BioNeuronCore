# Kir (106) — Inward Rectifier K⁺ (Kir2.1/KCNJ2)

## Источники
Kir2.1 (KCNJ2) — strongly inward-rectifying K⁺ канал.
- Single-channel **γ ≈ 30 пС** (симметричный K⁺; диапазон 22–31 пС).
- Сильное входящее выпрямление — Mg²⁺/polyamine блок.
- Voltage-dependent open probability.

## Биологические свойства Kir2.1

| Свойство | Значение |
|---|---|
| Single-channel γ | **30 пС** |
| Выпрямление | сильное inward (Mg²⁺/polyamine блок) |
| Po | voltage-dependent (падает при деполяризации) |

## Наша реализация (kir_channel_current, hh_biological.cpp + mod_106)

g_max=1.0 (state[3]);  open_prob: V_half=−80, k=8 (state[1/2]), tau=10;

## Статус: ✅ ДОСТОВЕРНО (исправлено 2026-08-14, согласовано)

1. g_max=1.0 → **γ=30 пС** (single-channel Kir2.1).
2. **Честный inward-rectification** — Woodhull N-сайтовый блок (Mg²⁺ 1 сайт + spermine 3 сайта):
   `f_open(V) = 1/(1 + [Mg]/Kd_Mg(V) + Σ [spm]^k/Kd_spm^k)`,
   `Kd(V) = Kd(0)·exp(−δ·z·F·V/(RT))`. Хелпер `kir_f_open(V)` (single-source).
3. Параметры: Mg²⁺ Kd(0)=0.3 мМ, δ=0.6, z=2, [Mg]=0.5 мМ; spermine Kd(0)=77.5 µM, δ=0.5, z=4, [spm]=1 µM, N=3.
4. Убрать GHK_P_PER_CM_S → GHK_GAMMA_PS_TO_P_CM_S; объём плагина → segment_volume.
5. Тест test_kir (γ неизменен, f_open(−120)>>f_open(+40), знак) — зелёный.
6. density — чистая плотность каналов (калибруется в интеграции, этап 6).

## Mean-field оговорка

Быстрые флуктуации канала (стохастические on/off блока) НЕ моделируются — усреднены в
steady-state `f_open(V)` (mean-field, как весь HH-стек). Стохастический шум каналов — отдельный
слой, не реализован (избыточен для CPG).
