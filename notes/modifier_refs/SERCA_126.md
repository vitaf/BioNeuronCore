# SERCA (126) — Ca²⁺-АТФаза эндоплазматического ретикулума

**Тип:** MOD_SERCA (126). Категория Ca²⁺-гомеостаз (ЭПР).
**Роль:** закачивает 2 Ca²⁺ из цитозоля в ЭПР за 1 ATP. Рефиллинг ER-депо после выброса IP3R/RyR.
**Статус:** ✅ ДОСТОВЕРНО (2026-08-19).

## Литература

- **Verkhratsky (2005)** *Physiol Rev* 85:201 — ЭПР как сигнальная органелла.
- **Lytton et al. (1992)** — SERCA2b: K_m(Ca²⁺) ≈ 0.27 µM, ниже оборот чем SERCA2a/3.
- **Vandecaetsbeek et al. (2009)** *PNAS* — SERCA2b кинетика: лимитирующий шаг дефосфорилирования k7=105 с⁻¹ (оборот ~100 с⁻¹).

## Модель (Hill-2 энзим, внутриклеточная мембрана)

```
J [моль/тик] = N · k_cat · f_Ca · f_ATP · (2 Ca/цикл) · dt / N_A   (одномолекулярная, 2026-09-22)
N     = density · area   (density — КЛЕТОЧНЫЙ параметр, молекул/µm²)
k_cat = 100 с⁻¹   (Vandecaetsbeek 2009: k7=105 с⁻¹)
f_Ca  = Ca²/(Ca²+K_m²),  K_m = 0.27 µM (Hill-2, 2 сайта)
f_ATP = ATP/(ATP+0.1 мМ)
Δ[Ca]i = −J/vol,  Δ[ER_Ca2] = +J/vol
return 0.0  // внутриклеточная мембрана ЭПР — нет тока плазмалеммы
```

- k_cat = 100 с⁻¹, density = 700/µm² (ER, Frontiers Immunol 2013). Убран суррогат V_max=0.05 нмоль/см²/с.
- **Плотность** (сколько SERCA в клетке) — через поле `density` (клеточный уровень), НЕ в модификаторе.
