# NEURON_HYPOTHALAMIC — голодающий нейрон гипоталамуса (головастик)

**Файл кода:** `BioNeuronStudio/src/neuron_library.h:250`
**Статус:** справочник для согласования (аудит #1)
**Биологический прототип:** орексигенный AgRP/NPY нейрон дугообразного ядра (ARC) гипоталамуса.

## Текущая реализация (что в коде)
```
name="HYPOTHALAMIC (hunger sensor)"; глутаматергический (nt_released=0)
soma 5.0µm, V_rest=-65, порог -38
MOD_HUNGER_SENSOR 0.8 (ATP-сенсор), MOD_IONOTROPIC_NAK 1.0,
MOD_PUMP_NAK 0.3, MOD_K2P_LEAK 0.03, + Ca²⁺/Cl⁻ гомеостаз
аксон 5 сегм (IONOTROPIC_NAK 0.3), 1 дендрит (пустой)
```

## Проблемы честности (что расходится с литературой)

1. **Нейротрансмиттер НЕВЕРЕН.** Реальный голодающий нейрон ARC — **ГАБКергический**
   (GABA + AgRP + NPY), НЕ глутаматергический. `nt_released=0` (глутамат) → должен быть `1` (GABA).
   Источник: van den Top 2004; обзоры ARC-цепей.
2. **Состав каналов — заглушка.** `IONOTROPIC_NAK 1.0 + K2P 0.03` не отражает реальный
   пейсмейкерный набор AgRP/NPY нейрона.
3. **K2P_LEAK 0.03** — неправдоподобно низкая (сенсорная заглушка, не физиология).

## Литературный состав (с источниками)

**Морфология** (van den Top et al. 2004, «Orexigen-sensitive NPY/AgRP pacemaker neurons in the ARC»):
- сома **~13.4 µm** (маленькая, круглая), **1–3 первичных дендрита**, спартанное ветвление.
- аксон → **PVN (паравентрикулярное) + LHA (латеральный гипоталамус)**.
- локально ингибируют POMC-нейроны (GABA).

**Электрофизиология** (van den Top 2004):
- RMP ≈ **−48.3 mV** (диапазон −40…−60 mV).
- R_in ≈ **1.3 GΩ**.
- **спонтанная (пейсмейкерная) активность**.

**Кондактансы** (van den Top 2004 + Choi 2024 + Stincic 2021):
- **I_AN** — аномальное (входящее) выпрямление K⁺, активируется < −80 mV (Kir-подобное).
- **I_TR / I_a** — транзиентный A-type K⁺ (регулирует частоту спайков).
- **Ih (HCN)** — гиперполяризационно-активируемый катионный ток.
- **T-type Ca²⁺** (низкопороговый).
- **GIRK (Kir3.x)** — поддерживает RMP, GABA_B-опосредованная гиперполяризация (Choi 2024).
- **M-current (KCNQ/Kv7)** — Kcnq3, возбудимость (Stincic 2021).

**Рецепторы:** GABA_A + GABA_B, AMPA/NMDA (глутаматный вход), лептин (LepR), грелин (GHSR),
инсулин (InsR), меланокортин MC3R.

## План правки (после согласования)

| Поле | Было | Станет |
|---|---|---|
| `nt_released` | 0 (глутамат) | **1 (GABA)** |
| `soma_radius_um` | 5.0 | **6.7** (≈13.4 µm ∅) |
| `resting_V_m` | −65 | **−48** |
| `threshold_mV` | −38 | −40 |
| состав сомы | IONOTROPIC_NAK+K2P | IONOTROPIC_NAK + K2P(реалистич.) + **PIR_TTYPE_Ca (T-type)** + **HCN (Ih)** + **KV42 (I_a)** + **GIRK/KIR** + насос |
| морфология | 1 пустой дендрит | **2–3 дендрита** (входы), аксон → PVH/LHA |
| микродомены | — | AIS (пейсмейкер, NaP?) |
| миелин | — | нет (короткие ARC-аксоны) |

**Плотности** — этап 6 (калибровка G→density γ/Po). Здесь фиксируем СОСТАВ и ЭФ-параметры
(RMP −48, R_in 1.3 GΩ как target для калибровки).

## Источники
- van den Top et al. 2004, «Orexigen-sensitive NPY/AgRP pacemaker neurons in the hypothalamic arcuate nucleus» — морфология, RMP, R_in, I_AN/I_TR, пейсмейкер.
- Choi et al. 2024, Molecules and Cells 47(11):100122 — GIRK1 поддерживает RMP NPY/AgRP, GABA_B.
- Stincic et al. 2021, Mol Metab — KCNQ3/M-current возбудимость AgRP.
- Примечание: у головастика Xenopus — гомологичные орексигенные NPY-нейроны гипоталамуса;
  детальные плотности берём из mammalian-прототипа (маркер источника).
