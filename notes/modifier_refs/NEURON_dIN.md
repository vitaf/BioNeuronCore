## Правило

Модификаторы `✅ ДОСТОВЕРНО` — НЕ менять. Калибруется ТОЛЬКО `density` в конфиге нейрона
(сколько каналов экспрессирует клетка). `density` = число каналов на µm².

## Формула перевода проводимость → density

`density[каналов/µm²] = G[мС/см²] × 10 / (γ[пС] · Po)`

Po — открытая вероятность канала. Гейтированные (Po_max≈1): BK, SK, Cav, HCN, Kir, Kv, KNa, T-Ca.
Постоянный Po<1: K2P (0.012), NaP (0.016) — их density домножается на 1/Po (иначе ток ничтожен).

Вывод: проводимость `G = N_cm2 · γ = density·1e8 · γ·1e-12 = density · γ · 1e-4 С/см²`
`= density · γ · 0.1 мС/см²` → `density = G / (γ·0.1) = G·10/γ`.

Проверка (Nav): gNa=52.5 мС/см², γ≈20 пС → density = 52.5·10/20 = 26/µm² ✓ (разумно).

## Порядок применения (Iterative CPG Tuning)

1. Выставить density по таблице. 2. Проверить V_rest dIN (−51) → подстроить NALCN/K2P.
3. Проверить single AP (порог −28, пик +29) → подстроить DIN_NAK/Ca. 4. Alternation.

## Single-spike механизм (почему DIN_NAK во всей клетке, а не Nav1.2 в аксоне) — 2026-08-27

- **Li, Soffe & Roberts 2015** (J Neurosci 35:9799, PMID 26156983): dIN single-spike =
  **инактивация Na-тока** (глубокая h-инактивация); порог растёт от деполяризации из-за
  инактивации Na⁺. Ребаунд = снятие Na-инактивации.
- **Winlove & Roberts 2012** (Eur J Neurosci 36:2926, PMID 22775205): в спинальных нейронах
  головастика **single-spike = высокий TEA-чувствительный медленный K (I_Ks)** (RB-нейроны),
  **repetitive = 4-AP-чувствительный быстрый K (I_Kf)** (DL-интернейроны). Высокий I_Ks
  предотвращает повторную стрельбу.
- **Вывод:** dIN single-spike = Na-инактивация + **I_Ks (медленный K)**. DIN_NAK (125) уже
  содержит обе: глубокая h + **Kslow (ns = I_Ks)**. Раздельные Nav1.2 (репетитивный) + Kv1.1
  (delayed rectifier) = I_Kf-путь (repetitive) — **НЕ годится** для single-spike dIN.
- ⇒ **Аксон/AIS dIN = DIN_NAK** (тот же Na/K single-spike канал, что сома — один канал по всей
  мембране). Nav1.2 (142) — молекулярный изоформ для других нейронов, остаётся в библиотеке.
