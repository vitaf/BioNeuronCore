# Cav3.3 (CACNA1I) — T-type Ca²⁺ канал (γ=11 пС)

**Тип:** низкопороговый (LVA) Ca²⁺ канал. Изоформа T-Ca с наибольшей γ и самой медленной кинетикой.

## Биофизический паспорт
| Параметр | Значение | Источник |
|---|---|---|
| γ (single-channel) | **11 пС** (Ba²⁺) | Monteil 2000 JBC (PMID 10749850); Perez-Reyes 2003 (PMID 12506128) |
| V½ активации (m) | **−43.8 мВ** | Klöckner 1999; Monteil 2000 |
| V½ инактивации (h) | **−72.5 мВ** | Klöckner 1999; Lee 1999 J Neurosci (PMID 10066243) |
| k_m | ~5–6 мВ | нужна лит |
| k_h | ~4–6 мВ | нужна лит |
| τ_m | ~30 мс | Klöckner 1999 |
| τ_h | ~137 мс | Klöckner 1999 |

## Отличие от Cav3.2 (PIR_TTYPE)
- γ = 11 vs 7.2 пС (больше)
- V½_m = −43.8 vs −48.4 мВ (положительнее)
- V½_h = −72.5 vs −75.6 мВ (положительнее)
- Кинетика ~6× медленнее → большой window-current

## Реализация (план)
MOD_CAV33 (191): GHK Ca²⁺ (z=2), m³h-гейтинг, V½_m=−43.8, V½_h=−72.5, γ=11, τ_m=30, τ_h=137.
