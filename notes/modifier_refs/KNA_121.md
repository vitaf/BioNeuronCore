# KNA (121) — Na⁺-активируемый K⁺ канал Slack/Slick (KCNT1/KCNT2)

**Тип:** MOD_KNA_CHANNEL (121). Категория #5 — ионные каналы Na/K/Ca/Cl.
**Роль:** Ca²⁺-независимый slow AHP — терминация длинных burst-ов через накопление Na⁺.
**Экспрессия в модели:** dIN (density 0.25), cIN (0.15) — `cpg_config.h`.

## Литература

- **Yuan A. et al. 2003**, *Neuron* 37:765–773 — «The sodium-activated potassium channel is
  encoded by a member of the Slo gene family». Slack (Slo2.2) = KCNT1.
- **Bhattacharjee A. et al. 2003**, *J Neurosci* 23:11681 — Slick (Slo2.1) = KCNT2.
- **Bhattacharjee & Kaczmarek 2013**, *Scientifica* 2013:354262 — обзор Slack/Slick.
- Таблицы: PMC9881102 Table 1, PMC4042479 Table 1 (SLO family).

## Характеристики (heterologous, CHO/HEK)

| Параметр | Slack (KCNT1/Slo2.2) | Slick (KCNT2/Slo2.1) |
|---|---|---|
| γ (унитарная проводимость) | **~180 пС** (183±3 пС) | ~140 пС (141±3 пС) |
| Na⁺ EC50 | **~41 мМ** (диап. 40–66) | ~89 мМ |
| Hill (Na⁺) | **~3.4** | ~2.6 |
| V-зависимость | слабая (нет S4) | заметная (есть S4) |
| Активация | медленная | быстрая |
| mean open time | ~118 мс | ~7.2 мс |
| Cl⁻-активация | есть (синергия с Na⁺) | есть (сильнее) |
| ATP-ингибирование | нет | да |

## Выбор изоформы для модели

**Slack (KCNT1)** — преобладающий нейрональный KNa. Канонические параметры
Yuan 2003: γ=180 пС, Na⁺ EC50≈41 мМ, Hill≈3.4. Slick — быстрый/ATP-чувствительный,
не соответствует роли «slow AHP».

## Mean-field оговорка

- **Нет стохастики каналов** (усреднено в steady-state Po).
- **Нет Cl⁻-коактивации** (Slack также Cl⁻-активируется — снижает порог по Na⁺ в интактной
  клетке; в mean-field берём только Na⁺-гейт по bulk [Na⁺]i).
- **Нет V-зависимости** — Slack слабо V-зависим (нет S4), в mean-field пренебрегаем.
- **τ** — медленная активация (сотни мс); slow AHP развивается за ~1–2 с.
