# NEURON MAGNETORECEPTOR — магниторецептор (СПЕКУЛЯТИВНО для Xenopus)

Справочник модификаторного состава. Тип: **градуальный механорецептор** (спекулятивный).

## Источник (литература)
- **«Cell Physiology Source Book — Electroreceptors and Magnetoreceptors»** — два гипотетических механизма: (1) **магнетит** (Fe₃O₄-цепочки → крутящий момент → механотрансдукция), (2) **криптохром** (радикальные пары Cry4, свето-зависимый).
- Магниторецепция у амфибий — предмет дискуссии; у Xenopus достоверно не показана.

## Биология
- Градуальный (не спайковый) механорецептор: магнитит-цепочка → механическое напряжение → MET-подобный ток.
- Либо криптохромный свето-зависимый сигнал (Cry4).
