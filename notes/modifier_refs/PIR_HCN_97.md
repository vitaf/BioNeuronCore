## Биологические свойства HCN (Ih)

| Свойство | Значение |
|---|---|
| Single-channel γ | ~1 пС (native If; HCN2 ~1.5 пС) |
| P_Na:P_K | **1:4** (K⁺ в 4× проницаемее Na⁺, E_rev ≈ −20..−30 мВ) |
| Активация | гиперполяризацией (m_inf = 1/(1+exp((V−V½)/k))) |
| V½ (generic) | −82 мВ (HCN_VHALF); HCN2 = −95 мВ |
| τ_open | медленная (HCN2 ~557 мс → sag) |
| cAMP | сдвигает V½ вправо (+10..+20 мВ) — суррогат DA в коде |

## Наша текущая реализация (pir_hcn_current, hh_biological.cpp + mod_97)

```cpp
V_half = state[1] (−82), k = state[2] (6), P_max = state[3] (0.05);
tau_open=250, tau_close=30; DA-сдвиг V_half +5 мВ;
P_base = P_max · density · GHK_P_PER_CM_S;         // ← магия
P_Na:P_K = 0.4:0.6  (т.е. 2:3);  open = m;
I_Na = GHK(P_base·0.4), I_K = GHK(P_base·0.6);  return −(I_Na − I_K).
```
